# 改进计划

> 目标：把工具从「跨省通道比选」推进到「符合交易规则的路径测算」。
> 编制日期：2026-09-14。

---

## 零、两份规则原文（本计划的依据）

**《省间电力现货交易规则》（2026 版，发改办体改〔2026〕275号复函）3.2 条原文：**

> **3.2.1 交易节点** 在省间电力现货交易中，一般情况下 1 个省为 1 个交易节点。当省内出现严重阻塞，且该阻塞相对频繁发生时，可定义多个交易节点。…… 同一省内的经营主体（不包含跨省消纳的机组）之间，不允许开展省间电力现货交易。
>
> **3.2.2 交易路径** 交易路径由卖方节点和买方节点之间的**跨省区交直流输电通道和省内重要输电通道顺序链接形成**。同一交易路径不重复经过同一交易节点。任意一对卖方、买方节点间可选择多条交易路径开展交易，**优先选择节点间输电价格（含网损折价）最低的交易路径**开展交易。

**3.5 条新增限定：** 交易节点内部存在交流断面越限等电网安全稳定风险时，节点内部相关的发电企业**不得在省间电力现货交易中买入电能**。

**这三条原文直接决定了本计划的三项核心改造**（对应下文 §1、§4、§5）。

## 一、两端增加省内节点落点（补全规则 3.2.2）

### 1.1 问题

当前模型在省界切断，两端省内段完全缺失。而规则 3.2.2 明确把「省内重要输电通道」列为交易路径的组成部分。

### 1.2 关键情报：路径集合不存在公开清单

经核查，**电力交易中心从未公开发布过「省间交易路径表」或「可交易路径清单」**。事实是：

- 2026 版规则 9.2.2「公开信息」逐条列出 a~k，与网络相关的只有 `b) 电网主要网络通道示意图（500kV 电压等级及以上）`，**不含交易路径清单**。
- 2021 版 9.2.2 曾含 `分交易路径各时段出清电价和出清电量`，2026 版**已删去「分交易路径」这一披露层级**。
- 国调中心口径（《省间电力现货市场实践与探索》）：`以直流输电系统为骨干，结合省间、省内交流关键断面，构建以省级电网为主要节点的省间现货交易网络模型……采用寻径算法搜索形成买卖节点间现货交易路径。`

**结论：路径是运行时算出来的，没有清单可依。** 因此不能用「过滤到官方集合」的办法，只能用规则条款的推导约束（见 §4）。

### 1.3 落点节点不是从零建模，而是已有数据未用上

目前 `src/extra.json` 里已经存了 **91 个真实换流站/变电站**（含名称、精确到乡镇村的站址、经纬度），但只用于地图打点，**没有进入成本模型**。

### 1.4 改造方案

把路径结构从「省 → 省」扩展为：

```
机组
 └─[送端省内段]→ 送端省交易节点 ─[跨省区通道…]→ 受端省交易节点 ─[受端省内段]→ 负荷
```

| 环节 | 费用项 | 依据 |
|---|---|---|
| 送端省内段 | **送出省输电价格** + 送省外线损率 | 发改价格〔2018〕1227号第五条；各省第四监管周期通知 |
| 跨省区通道 | 专项工程输电价 + 通道线损 | 发改委核价文件 |
| 受端省内段 | 受端省网输配电价（220kV 及以上两部制） | 发改价格〔2026〕1077号附件1 |
| 受端 | 政府性基金及附加 | 各省落实通知 |

**⚠️ 本项同时修复一个此前未被发现的错误：**

发改价格〔2018〕1227号第五条明确，跨省跨区市场用户的购电价格构成为：

> 市场交易价格 ＋ **送出省输电价格** ＋ 跨省跨区专项工程输电价格及损耗 ＋ **落地省省级电网输配电价** ＋ 政府性基金及附加

**当前模型的落地价公式里缺失「送出省输电价格」这一项。** 该项按省取值（四川 35.0、云南 47.8、山西 21.7、广西 18.0 元/兆瓦时），在约 490 元/兆瓦时的落地价中占 4%~10%，是系统性低估。

### 1.5 落点电压等级

各省输配电价表的最高档为「220kV 及以上」，500kV 与 1000kV 落点共用该档。因此**落点电压等级目前不影响数值**，但需作为通道属性记录下来——将来若省级电网细分档位，可直接切换。

## 二、五个建模问题的解决

### 问题 1｜单一容量电价工程口径不兼容 ⚠️ 最易被忽略

**核实结果**：国网 2025 年（36 项）与 2026 年（40 项）跨省跨区专项工程价格表**全量排查后确认只有 2 条**是单一容量电价制：

| 工程 | 送→受 | 容量电价 | 核价文号 |
|---|---|---|---|
| 辛洹线（辛安—洹安 500kV） | 河北邯郸 → 河南安阳 | 40.0 元/千瓦·年 | 发改价格〔2018〕1227号 |
| 云霄直流（闽粤联网） | 福建 ↔ 广东 | 115.0 元/千瓦·年（2.3 亿元/年） | 发改价格〔2022〕1604号 |

制度依据：发改价格规〔2017〕2269号第八~九条——「以联网功能为主的专项工程按**单一容量电价**核定，由联网双方共同承担；以输电功能为主的按单一电量电价核定」。

**解决方案**：

1. 为通道增加 `priceType` 字段：`energy`（单一电量制，38 条）/ `capacity`（单一容量制，2 条）
2. 容量制工程不填「输电价」，改为填 `capPrice`（元/千瓦·年）与 `annualHours`（年利用小时）
3. **比选时折算等效度电成本**：`等效度电 = capPrice × 1000 ÷ annualHours`，标注为折算值而非核定价
4. **⚠️ 不可直接按 0 计**：云霄直流自 2026-06 起已引入输电权交易，报价区间 25.6~100 元/兆瓦时，边际成本不再为 0

**政策动向**：2025-11 发改委修订四个办法，明确「对以输送清洁能源电量为主的跨省跨区专项工程**探索实行两部制或单一容量制电价**」——存量虽只有 2 条，但未来会扩围，代码需预留。

### 问题 2｜额定容量 ≠ 可用输电能力 ⚠️ 影响最大

**核实结果**（用最新公开数据，不沿用单一报告）：

| 工程 | 额定 | 实际输送能力 | 来源年份 |
|---|---|---|---|
| 锦苏 / 复奉 / 宾金 / 金塘 / 庆东 / 昆柳龙 / 兴安 | — | **等于额定** | 近期报道 |
| 吉泉 | 12000 | 11000 | 国网安徽 |
| 锡泰 | 10000 | 8300 | 江苏省政府 |
| 中衡 | 8000 | 8000（此前 4000） | 2025-10 双极投产 |
| 雁淮 | 8000 | 8000 | 2022-07 首次满载 |
| 陕武 | 8000 | 5499 | 2026-06 峰值 |
| **昭沂** | 10000 | **5300** | 2021 最大送受电 |
| 天中 | 8000 | 5400 | 世行 2018 |
| 祁韶 | 8000 | 4000 | 世行 2018 |
| 雅湖 | 8000 | 4600 | 2021 大负荷 |
| 金永 | 8000 | 4000 | 2025-09 |
| 坤渝 | 8000 | 6000 | 兵团广电 |
| **青豫** | 8000 | **未获取**（夜间仅额定 10%、年利用 2000h vs 设计 4500h） | — |
| **扎青 / 宝合 / 云广 / 高肇 / 甘浙** | — | **未获取** | — |

**三条重要结论：**

1. **必须逐线取数，不能一刀切打折。** 17 条有明确实际值，其中 7 条实际＝额定，说明「额定↔实际」不是系统性折半。
2. **ATC（可用输电能力）公开渠道 0/27 全部未获取。** 国家能源局可靠性报告只给额定输送容量，交易中心披露到电量/成交电力，跨区通道的 ATC 无公开口径（TRM/CBM 取值我国不公开）。
3. **此前引以为据的 4 个数字同源且过期。** 天中/昭沂/祁韶/灵绍 四条的「实际值」全部出自 2018 年西安交大—世行报告，昭沂此后已由 4500 升至 5300。**不能用一份 8 年前的报告当作现状。**

**解决方案**：

- 通道增加 `capActual`（实测/报道的实际输送能力）与 `capBasis`（口径：额定 / 输送能力 / ATC）与 `capSrc`
- 容量校验优先用 `capActual`，回退 `rated`；界面标注该值口径与来源年份
- 对 `capActual` 缺失的 6 条，明确显示「实际能力未获取，按额定校验，结果偏乐观」
- **不引入虚构的折扣系数**——宁可标注「未获取」，也不用统一系数糊弄

### 问题 3｜线损按核定值算的政策依据

发改价格〔2018〕1227号第四条：

> 各项工程实际运行中输电线损率超过定价线损率带来的风险由电网企业承担，低于定价线损率带来的收益由电网企业和电力用户各分享 50%。

**结论：按核定线损率计算是正确且有政策依据的，这一项不是可谈判项。** 当前实现已正确，需在界面补充依据说明，避免用户在商务谈判中让错。

**另一处需修正**：技术文献口径为「**输电费按最优路径收取、线损按实际路径承担**」——即费用与损耗可能对应不同路径。当前模型两者都用同一条路径，需在界面注明这一简化。

### 问题 4｜两部制容量电费

**核实结论**：

- **不额外收取。** 发改价格〔2020〕1441号第二条：「区域电网容量电价作为上级电网分摊费用**通过省级电网输配电价回收，不再向市场交易用户额外收取**」；〔2023〕532号延续同一表述。
- 省级电网两部制的容量电费，按**受电变压器容量（元/千伏安·月）**或**合同最大需量（元/千瓦·月）**择一计收。
- **关键**：该费用**与电量来自省内还是省外无关**，是按容量计收的固定成本。

**解决方案**：

- 不在「元/兆瓦时」的落地价里叠加容量电费（会重复计算）
- 新增**独立的容量电费测算器**：输入受电变压器容量与年用电量，输出「容量电费 ÷ 年电量」的度电分摊额，作为落地价的附加参考
- 界面注明：容量电费与省间/省内电量无关，故不参与路径比选

### 问题 5｜落点电压等级

见 §1.5。当前各省级电网最高档为「220kV 及以上」，500kV/1000kV 落点共用该档，**数值上无差异**，但落点信息需作为通道属性记录，为将来细分档位预留。

**同时补一项缺失**：现行公式缺少「送出省输电价格」（见 §1.4），这是本轮发现的最实际的数值错误。

## 三、估算占比与可信度标注

数据可信度已有四档标记（`gov` / `grid` / `region` / `est`），本轮再增加两个维度：

| 字段 | 含义 | 用途 |
|---|---|---|
| `capBasis` | 容量口径：`rated` / `cap` / `atc` | 容量校验的乐观程度 |
| `priceType` | 计价方式：`energy` / `capacity` | 比选口径是否可比 |

## 四、剔除现实中不存在的选项

### 4.1 官方路径集合不存在，但有更硬的约束

既然拿不到官方清单，就用规则原文推导约束。**规则本身给的三条约束比任何清单都硬**：

1. **交易网络是等值模型，不是物理全网**
   节点 = 省级电网（约 30 个），边 = `跨省区交直流输电通道 + 省间交流断面 + 区域电网虚拟通道 + 省内重要输电通道`。
   → **当前图里 24 条 500kV 省间联络线需重新审视**：其中一部分是物理联络线而非省间现货交易通道，纳入图会导致路径数虚高。

2. **「同一交易路径不重复经过同一交易节点」**（3.2.2）
   → 只保留简单路径。已实现。

3. **「优先选择节点间输电价格（含网损折价）最低的交易路径」**（3.2.2）
   → **这是最有效的一条**：结算与定价只认成本最低路径。因此输出层应对每对节点给「最低成本路径 + 有限备选」，而不是全量并列。

### 4.2 落地方案

- **主方案区**：落地成本不劣于最优路径 X%（默认 10%，可调）的方案
- **其余折叠**：标注「另有 N 条成本高出 X% 以上的方案」，可展开
- **默认跳数由 3 降为 2**，并注明「放宽跳数会产生现实中不会采用的绕行组合」
- 图中的 24 条省间联络线增加 `tradable` 标记，区分「可交易通道」与「物理联络线」

### 4.3 量级预期

节点数约 30、边为「点对点直流 + 区域间交流断面」时，节点度数有限，在简单路径约束下跨区长途节点对（如四川→江苏）的路径数应为**个位数**，与现在全网拓扑枚举出的 20 条（3 段内）/ 162 条（5 段内）不在同一量级。

**注意**：官方未公布任何「某对送受端实际路径条数」的实例，上述为基于网络规模的推断，属**未获取**状态。

## 五、费率库界面改造

- **通道列表改为折叠卡片**：默认只显示通道名 / 起止 / 输电价 / 线损率；展开后显示容量、口径、文号、原文摘录、调价历史、送出省价等全部字段
- **省级参数同样折叠**
- **顶部搜索框**：按通道名、别名、省份、文号模糊匹配，实时过滤
- 增加筛选：按可信度档位（发改委核定 / 国网披露 / 区域口径）、按计价方式（电量制 / 容量制）

## 七、明确不做

| 项 | 原因 |
|---|---|
| 全省内网建模 | 一省 220kV 以上变电站数百个，数据不可得；对路径比选边际价值递减 |
| 潮流计算 / GSDF | 需电网内部灵敏度矩阵，公众渠道拿不到；南网那套模型需内部数据 |
| 自建价格预测 | 属另一专业领域，应接现有预测服务 |
| 虚构 ATC 折扣系数 | ATC 参数我国不公开，宁标「未获取」也不编系数 |
| 用单一报告推算全部通道的实际能力 | 已证伪：四条数字同源自 2018 年报告，昭沂已变化 |
