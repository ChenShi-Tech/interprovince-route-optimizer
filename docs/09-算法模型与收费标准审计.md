# 算法模型与收费标准审计（2026-09-17）

## 业务结论

本应用定位为**省间中长期交付成本与报价测算**，默认交付点为受端省间交易节点。送端报价、受端目标交付价是用户输入；预填数字只是演示参考，不是市场实时报价。现货保留待拓展入口，不提供现货出清或结算。

本次覆盖全部 30 个省级模型节点、64 条通道的算法与来源状态审查。**通过公式回归不等于所有路径均可交易、全部参数均可用于实际结算。** 中长期交易公告、合同参考点和费用边界仍需逐笔匹配。

## 修复及其原因

| 问题 | 当前处理 |
|---|---|
| 皖苏、苏沪等接口重复使用省级送出价收费 | 共用接口不收独立工程费；送出省费仅交易起点一次，报价已含时不加 |
| 共用交流接口逐条加损，又可能收区域网损 | 同区域共用交流接口计费损耗为 0；区域损耗按收费区域一次加入通过率链 |
| 现货条款误作中长期通用结算依据 | 默认按共用网络收费区域归集；可按公告选择另计受端区域；不强制套现货受端统一收费/卖方省内线损承担条款 |
| “送端净收益”被误读为利润 | 改为“可接受送端报价”，由目标交付价按同一费用模型反算；旧 senderNet 字段保留但语义改变 |
| 送出关口报价可能已含省内费用 | 增加报价边界；送出关口报价不再加送出省费、送端省内网损；电能量报价可选择省内网损另计 |
| 区域网损缺失被误当作 0 | 提供未计入、历史参考、手填三种情景；历史和手填均标记假设，currentPct 保持 null |
| 到户单价乘省间交付量导致金额口径不一致 | qty 始终为省间交付量；到户扩展金额以 consumerQty 为单价基数 |
| 估算容量、历史断面被当成可用能力 | 标为参考参数；未越限不等于 ATC 已确认；交流容量明确标 estimate |
| 参数日期、缺失、单位及方向展示问题 | 校验交易日期/数值；删除 30 元/MWh 无依据兜底；修正西藏适用日、两个零损耗参数、断面错配与反向站点展示 |
| 负价与平行通道 | 负价仍保留最低成本路径；敏感性路线识别包含边 ID；恰好达到枚举上限不误报截断 |

## 数学口径

对每交付 1 MWh：

```
D = 所有计费损耗环节通过率的乘积（含所选区域环节，各区域一次）
L = 1/D - 1
E = 报价未覆盖且选择另计时：1/D × 送端省内损耗率/(1-送端省内损耗率)；否则 0
F = 未含的送出省费 × 首段入口系数
  + Σ 专项工程输电价 × 该工程出口系数
  + Σ 适用区域电量价 × 该区域出口系数
A = 1 + 买方网损分担比例 × L + E
节点交付费用小计 = 送端报价 × A + F
可接受送端报价 = (受端目标交付价 - F) / A
```

各出口系数含下游损耗，不含该环节自身损耗。区域损耗不是按接口复制的物理线损。送端省内损耗另计时以送端报价估算购损价格；实际合同购损口径可能不同。

到户扩展：`到户单价=节点小计/(1-受端省内损耗率)+省内输配电价+基金`；`consumerQty=qty×(1-受端省内损耗率)`。故总额为 `节点小计×qty+(省内输配电价+基金)×consumerQty`。系统运行费、容量/需量电费及地方分摊等未形成完整到户账单，名称保持“已列费用小计”。

## 新疆→安徽→江苏→上海复算

长三角2026中长期细则第36条（PDF第10—11页，已视觉核对）明确：落地侧价格包含送出省费用、华东区域电量费与区域网损；反推上网价格为 `(落地价格-华东输电价)×(1-华东网损率)-含送省损耗的送出费用`。本模型在区域内纯交流路径及对应报价边界下与该式一致，已加入独立测试。取消接口重复计损不等于免除整个区域网损。

假设：送端报价 240 元/MWh，报价已覆盖送端省内网损、未含送出省输电费；新疆送出价 34.3，吉泉 82.9，吉泉计费网损 7%，华东区域价 9.2；买方承担跨省计费损耗。

| 情景 | 独立手算 | 元/MWh |
|---|---|---:|
| 未计区域网损 | `(240+34.3)/0.93+82.9+9.2` | 387.0462 |
| 华东历史参考 1.59% | `((240+34.3)/0.93+82.9)/0.9841+9.2` | 393.1511 |

两者均为特定边界下的测算。吉泉采用库内国网披露价，不能称为全部发改委核定可结算结果。若 240 未覆盖送端省内网损，应选另计；若为全含送出关口价，应选择对应边界。交流接口仍用于路径连通及参考容量估算，不能代表真实潮流只走这些线路。

## 公共数据核验

1. **中长期主规则**：[发改能源规〔2025〕1656号](https://www.ndrc.gov.cn/xxgk/zcfb/ghxwj/202512/t20251226_1402666.html)，2026-03-01 起实施；归档 S31。合同价格、参考点、分时曲线和实际结算应按适用实施细则与合同确认。长三角 2026 细则归档 S30：[华东能源监管局原件](https://hdj.nea.gov.cn/dtyw/tzgg/202604/P020260417606107102994.pdf)。长三角规则不能直接认证新疆跨区送入全链路的合同收费范围。
2. **省级价格**：[1077号附件1](https://www.ndrc.gov.cn/xxgk/zcfb/tz/202607/P020260710613207914509.pdf)与库内原件逐字节一致。独立解析 29 个省级主体的默认两部制高压电量价、省内损耗率、送出价、送省外损耗率，共 116 项与库值匹配，结果见 [price-primary-audit.json](price-primary-audit.json)。这不涵盖每一用户电压档或基金标准的本次重新认证。河北默认南网、内蒙古默认蒙西、陕西不含榆林、广东存在分区，页面保留适用主体提醒。
3. **西藏**：1077附件1没有西藏省表，改用[西藏发改委通知](https://drc.xizang.gov.cn/fgdt/jggl/202607/t20260731_552206.html)并标 2026-10-01 起，默认节点交付不加省内价；提前使用该到户价格会拦截。其基金及省内线损仍缺项。
4. **区域电量价**：[1077号附件2](https://www.ndrc.gov.cn/xxgk/zcfb/tz/202607/P020260710613208195785.pdf)明确含税、不含线损；华北 10.8、华东 9.2、华中 25.6、东北 16.4、西北 12.1 元/MWh。区域容量电价经省级输配电价回收，不能再整项叠加。京津唐部分交易免华北电量电费，省级模型无法自动识别电厂主体，保留待确认项。
5. **区域损耗**：在国网编制的第三监管周期历史公开表中核对华北 2.42%、华东 1.59%、华中 2.54%、东北 2.35%、西北 1.96%。[公开转载表](https://jsnenghui.com/Uploads/Editor/2025-03-13/67d27fc4c0c47.pdf)标题为 **2024 年**；地址中的 2025 不是适用年度。归档 S29 并注明转载来源。该表不是当前第四周期备案文件，五区 currentPct 均为 null。本次未找到足以确认五区第四周期继续适用的完整备案原件；不得用历史值冒充本期核定值。
6. **专项工程**：按已归档价格原件、含损标识与单位逐项审阅；独立解析842附件31行，29行匹配、2行由后续文件调价，结果随 price-primary-audit.json 保留。842附件“元/千千瓦时”等于元/MWh；558号、404号涉及的含损价格不再追加网损。辛洹“不计线损”和白鹤滩配套交流“不计线损”从缺失修正为明确 0。政府历史价格与国网披露价保留来源级别，缺生效日/来源版本的路径仍提示待核。容量制辛洹、云霄只按边际费用情景展示，输电权价格与容量分摊尚不能当作已付清。
7. **专项计量原则**：[1490号附件4](https://www.ndrc.gov.cn/xxgk/zcfb/ghxwj/202511/P020251127364890979771.pdf)第十八条涉及落地端计量与线损偏差处理。本工具据选定收费单元做出口电量折算，未代替运行计量。
8. **用户提供的现货规则**：[2026年4月原件](https://www.ndrc.gov.cn/xxgk/zcfb/tz/202604/P020260424330206042944.pdf)，已研究4.3.1折算公式、3.3含损价格及7章结算。其96时段申报、出清、边际价格和特定费用承担约定属于未来现货模块，不直接作为中长期合同结算算法。

## 界面默认口径调整（2026-09-17）

依据长三角跨省中长期实施细则（2026）第三十六条（S30 PDF 第 10—11 页，已视觉核对原文）：

- （一）购电方省间联络线落地侧价格由发电侧上网价格、送出省外送输电价格（**含送出省外送输电网损**）、华东跨省电量输电价格、**华东跨省输电网损**等构成；
- （三）发电企业上网价格 =（购电方省间联络线落地侧成交价格 − 华东跨省输电价格）×（1 − 华东跨省输电网损率）− 送出省外送输电价格。

结合 1077号附件1 各省表注4（外送电送出省输电价格「含税、不含线损」，送省外上网环节线损率单列），界面默认改为：送端省内网损 **另计**、区域网损 **计入第三监管周期参考值**。区域网损率仍非第四周期核定值，结果页保留「待核实」提示；「不计入」保留为缺项基准情景。算法层在未传字段时的缺省（included / exclude）不变，回归基线与本文手算用例均显式固定该口径，数值不受界面默认值影响。

默认口径下新疆→上海（送端报价 240，经吉泉直流 + 华东区域网架）为 393.86 元/MWh（区域网损不计时 387.74）；四川→江苏最低价回到锦苏直流直达。区域费范围「途经区域各计一次」仍是待确认假设：第三十六条管长三角区域内跨省交易，直流直接落到受端省时是否另计华东区域费，须以北京电力交易中心跨区跨省细则或交易公告为准。

## 尚不能认证的范围

- 北京交易中心2026版跨区跨省中长期实施细则的完整原件及每笔交易公告、合同费用约定，不能由全国基本规则替代。
- 区域损耗当前备案值、背靠背独立费用/核定损耗、点对网专属电源适用条件、未接入的系统运行费与实际分摊。
- 全国基金标准、全部分档价格的当期用户适用性，本次 116 项核验不包含这些内容。
- 省级单节点模型无法区分所有经营区和特定电厂；图连通不证明交易路径获准。静态方向不代表中长期规则禁止反向组织。
- 10 个历史断面仅供参考；真实 ATC、安全校核、分时合同曲线、执行计量、绿电环境价值及差价/差量结算未实现。
