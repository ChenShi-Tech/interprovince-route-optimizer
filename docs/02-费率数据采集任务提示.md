# 费率数据采集 —— Agent 任务提示

> 用途：让 agent 自主检索、抽取、校验跨省跨区输电价格与线损率，产出可导入测算工具的结构化费率库初稿。

---

## 使用说明

1. 把下面「任务提示」整段复制给 agent（WorkBuddy / 其他具备联网检索能力的 agent）。
2. 先只跑**首批 5 条试点通道**，确认产出格式与质量达标，再放开到全量 30–50 条。
3. 产出物是三个文件：`tariff.json`、`sources.md`、`gaps.md`。**`gaps.md` 比 `tariff.json` 更有价值**——它告诉你哪些数据根本拿不到，这决定项目风险在哪。

---

## 任务提示（可直接复制）

````text
# 任务：采集跨省跨区电力交易通道的公开核定费率数据

## 目标

为「省间电力现货交易路径优选测算」工具采集费率数据，产出结构化、可追溯、可核验的费率库初稿。
这些数据将用于计算跨省送电路径的输电费、网损、落地购电成本。

## 你需要的核心能力

联网检索 + 官方文件抽取 + 严格的结构化输出。
**你的价值在于准确与可追溯，不在于覆盖数量。**宁少勿错。

## 数据范围

首批 5 条试点通道（先做这 5 条，做完停下来等确认）：
1. 锦屏—苏南特高压直流（四川 → 江苏）
2. 向家坝—上海特高压直流（复奉直流，四川 → 上海）
3. 云南—广东特高压直流（云广直流）
4. 灵州—绍兴特高压直流（宁夏 → 浙江）
5. 锡盟—泰州特高压直流（内蒙古 → 江苏）

确认通过后再扩展到：昌吉—古泉、酒泉—湖南、青海—河南、雅中—江西、
白鹤滩—江苏、白鹤滩—浙江、哈密—郑州、陕武直流、上海庙—临沂、
扎鲁特—青州、银东直流，以及蒙西—天津南、榆横—潍坊、皖电东送、
浙北—福州等 1000kV 特高压交流工程。

## 需要抽取的字段（每条通道一条记录）

- 通道名称、送端省、受端省、类型（直流 / 交流）、电压等级
- 额定输电容量（兆瓦）
- **跨省跨区专项工程输电价格**（元 / 兆瓦时）
- **综合线损率 / 输电损耗率**（百分数）
- 计费电量口径（按送端上网电量 / 按受端落地电量 / 未明确）
- 生效日期、失效日期
- 来源：文件标题、文号、发布机构、发布日期、原文 URL、承载该数值的原文摘录

## 数据源优先级（严格按此顺序检索）

1. **国家发展和改革委员会**（ndrc.gov.cn）价格司 / 政务公开。
   跨省跨区专项工程输电价格由发改委核定并以通知形式发布，文号形如
   「发改价格〔20XX〕XXX号」。这是最高权威源，一切以它为准。
   注意文件名可能不含工程全称，需要用「输电价格」「跨省跨区专项工程」等
   关键词配合年份检索。
2. **各省发展和改革委员会**价格处。省级电网输配电价表（分电压等级）。
3. **北京电力交易中心**（bjpx.com.cn）—— 省间交易信息披露、通道输电价格、
   可用输电能力。覆盖国家电网经营区。
4. **广州电力交易中心**（gzpx.cn）—— 南方区域，云南 / 贵州 / 广西 / 广东。
5. **国家能源局**（nea.gov.cn）及派出机构（华北、东北、西北、华东、华中、
   南方能源监管局）—— 通道核准文件、监管报告。
6. **国家电网、南方电网** 电力交易平台的信息披露栏目。
7. **各省电力交易中心**（四川、云南、江苏、浙江、山东、广东等）。
8. **中国电力企业联合会**（cec.org.cn）—— 统计月报、电价数据。
9. 上市公司公告（若通道资产涉及上市主体）。

以上域名以实际可访问者为准，若某站点不可达，记录在 gaps.md 中并换用其他权威源。
行业媒体（北极星电力网、中国能源报等）**只能作为线索**，不能作为数据来源——
必须回溯到它们引用的原始文件。

## 单位与口径规范（必须显式记录换算过程）

- 输电价格：原文常见「元 / 千瓦时」→ 输出统一为「元 / 兆瓦时」，乘以 1000。
  例：0.0438 元/千瓦时 = 43.8 元/兆瓦时。
- 容量：原文常见「万千瓦」→ 输出统一为「兆瓦」，乘以 10。
- 线损率：原文可能是百分比或小数，统一为百分数。
- 必须标注原文是「含税」还是「不含税」。

## 真实性铁律（最高优先级，违反即任务失败）

1. **不得推测，不得用相近工程的数值代替，不得凭常识或经验填写。**
   找不到就写 null，并在 gaps.md 中写明已检索过的来源与未果原因。
2. **每一条数值必须附原文摘录**，且摘录必须能在给出的 URL 页面中定位到。
   无法给出摘录的数值一律丢弃。
3. **不得混淆文号、发布日期、生效日期。** 核定文件常有「自 XXXX 年 X 月 X 日起
   执行」的表述，生效日期与发布日期不同。
4. **不得使用需要登录、付费或未经授权获取的数据。**只用公开发布或官方披露渠道。
5. 同一数值有多个来源时，以发改委核定文件为准，并在备注中记录其他来源。
6. 若发改委已核价但文件未公开，在 gaps.md 中标注「已核价未公开」，
   **不要用媒体报道的数字替代**。

## 输出格式

### tariff.json

```json
[
  {
    "name": "锦屏—苏南特高压直流",
    "from_province": "四川",
    "to_province": "江苏",
    "type": "DC",
    "voltage": "±800kV",
    "capacity_mw": null,
    "tariff_cny_per_mwh": null,
    "loss_rate_pct": null,
    "billing_basis": "送端|受端|未明确",
    "effective_from": "YYYY-MM-DD",
    "effective_to": null,
    "tax_included": true,
    "source": {
      "doc_title": "",
      "doc_number": "",
      "issuer": "",
      "publish_date": "",
      "url": "",
      "excerpt": ""
    },
    "confidence": "high|medium|low",
    "note": ""
  }
]
```

confidence 判定：直接来自发改委核定文件原文 = high；
来自交易中心或能源局披露 = medium；仅有间接线索 = low 并说明。

### sources.md

一张表，列出所有用到的文件：文号 / 标题 / 发布机构 / 发布日期 / URL /覆盖了哪些通道。

### gaps.md

分三部分：
- **未获取的字段**：哪条通道的哪个字段没找到，已尝试过哪些检索路径。
- **存在冲突的数据**：同一字段多个来源不一致，各自数值与出处。
- **待人工确认的疑点**：例如文件表述含糊、计费口径不明、是否已废止。

## 执行方式

- **分批进行**，每批 5 条通道。每批完成后先输出结果，等确认再继续下一批。
- 每条通道写库前做一次**反向验证**：用文号与工程名再检索一次，
  确认不存在更晚的修订或废止文件。
- 检索用中文关键词组合，例如：
  「<工程名> 输电价格 核定」「发改价格 <工程名>」「跨省跨区专项工程 输电价格」
  「<工程名> 线损率」「<送端省> 输配电价表」。
- 时间不够或来源不可达时，**优先保证已采集数据的准确性**，把缺口如实写进 gaps.md。

## 现在开始

先做首批 5 条试点通道。完成后输出 tariff.json、sources.md、gaps.md 三个文件，
并简要说明：5 条中有几条拿到了完整数据、几条完全拿不到、主要卡在什么环节。
````

## 附：常见陷阱与验收清单

### 检索时容易踩的坑

| 陷阱 | 表现 | 应对 |
|---|---|---|
| 混淆三类价格 | 把「省级电网输配电价」当成「跨省跨区专项工程输电价」 | 前者是省内分电压等级的输配电价表；后者是发改委针对具体跨省工程核定的价格。两者用途完全不同，不能互相替代 |
| 买到旧版文件 | 核价文件有多次修订，检索到的是早期版本 | 每条通道做反向验证，用文号再搜一次确认无更新 |
| 只看媒体报道 | 媒体报道给了一个数字，没有原始文件 | 必须回溯到发改委通知原文；回溯不到就写 null |
| 附件里的数据 | 部分核价文件正文只有一句话，具体价格在附件 Excel / PDF 里 | 必须打开并解析附件，不能只读正文 |
| 扫描件无法检索 | 老文件是图片 PDF，关键词搜不到正文 | 需要 OCR；OCR 结果必须人工复核关键数字 |
| 计费口径不明 | 文件没写按送端还是受端电量计费 | 标为「未明确」并在 gaps.md 中列为待确认，不要猜 |

### 验收清单（收到 agent 产出后逐条核对）

- [ ] `tariff.json` 中每条非 null 数值都能在 `sources.md` 里找到对应文件
- [ ] 每条记录的 `excerpt` 是原文摘录，不是改写或概括
- [ ] 单位换算正确（元/千瓦时 ×1000 = 元/兆瓦时）
- [ ] `effective_from` 与 `publish_date` 没有混淆
- [ ] `gaps.md` 中的缺口数量合理——**如果 5 条试点通道全部拿到了完整数据，反而要警惕**，说明可能存在编造
- [ ] 抽查 2 条记录，人工打开 URL 核对原文

### 一个务实的预期

按公开渠道的实际可得性，**跨省跨区专项工程输电价格**通常能从发改委文件中拿到（这是核价公开的部分）；
但**各通道的核定线损率**公开程度差异很大，很可能有相当比例拿不到。这不算失败——
这恰恰是需要在项目早期暴露的风险：线损率拿不到，网损折价就只能用测算值或与电网协商口径，
这会直接影响「三口径并列」功能能否发挥作用。
