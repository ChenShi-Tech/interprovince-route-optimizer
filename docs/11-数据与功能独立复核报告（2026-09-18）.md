## 2.1 已确认的功能缺陷（高严重度）

**H1｜截断候选集被当作通道组件全集，通道筛选出现假阴性**

- 机理：逐层枚举累计命中 `ENUM_CAP=800` 即提前退出；`availChannels` 与 `mustHave` 过滤都只用截断后的候选集；界面在所选通道不在 `availChannels` 时静默删除并重算。
- 证据：`src/app/algo/solve.js:115-122/128-134/139-146`、`src/app/algo/paths.js:21-37`、`src/app/ui/calc.js:401/419-425`；`docs/03-数据接口说明.md:213` 承诺候选清单取自已通过绕行筛选的「完整候选集」。
- 影响面：653 个有解省对中 184 对截断、86 对丢失 ≥1 条通道；用户会误认为通道不可用或无方案，且**界面内无法找回**。
- 附：合成反例显示 DFS 前缀 + 截断可丢弃真实最优（568.182 vs 550.909，17.273 元/MWh，且 `truncated=false`）。

**H2｜省间联络线仍带估算容量并参与越限判断**（**已独立复核**）

- 见 D6：14 条 `capBasis='estimate'` 仍在，`cost.js:160/166/199`、`solve.js:204` 的越限判定只看 `cap` 有无值、不看口径；`tools/build.mjs:135-137` 注释与 `CODEBUDDY.md:216`、`docs/gaps.md:215` 均称「一律留 null」。

**H3｜端侧按契约组装数据会漏掉 `LOSS_OF`，省内网损静默按 0 计**（**已独立复核**）

- `LOSS_OF` 只在 `src/app/data.js:25-31`（界面层）派生，被 `src/app/algo/cost.js:58/134/144`、`src/app/algo/solve.js:41` 消费；`shared/app-data.json` 与 `docs/03` 全文均无该字段。
- 后果：端侧照契约实现会静默把省内网损按 0 计（实测 SC→JS 到户 Δ=12.6056 元/MWh），且**基线测试仍 989/989 通过**（基线口径 `included/exclude` 不读 `LOSS_OF`）。
- 这是「算法层可原样复用」在**数据层**被击穿，不是算法层。

**H4｜回归门禁自证失效：`baseline2` 覆写答案自比，费率快照还原使费率错值全绿**

- `tools/baseline2.mjs:89` 无条件覆写已提交基线，`:95-115` 随即用新基线自比；`tools/baseline-check.mjs:53-54` 用基线快照覆盖 `CH`；91 条通道中 73 条在测试源码 0 命中；数据审计脚本不在门禁。

- 附：`baseline2.mjs:83` 的 warning 是**手写常量**（称 38/8/24，实测 `{gov:45,grid:8,est:5,region:33}`）。

**H5｜回归基线口径与产品默认口径不一致，端侧验收规模不匹配**

## 2.3 被验证推翻的伪缺陷（避免误改）

1. 「没有任何独立于实现的外部真值对照」——**不成立**：`test-model-audit.mjs` 有独立手算锚点（XJ→SH 387.0462 / 393.1511；长三角第 36 条正反算）。真实缺口是**覆盖面窄**，不是「全无对照」。
2. 「14 条估算容量是未登记的假设」——不成立：属**数据缺陷**（文档已声称已修），不是假设。
3. 「到户分项金额基数与 `docs/09:42` 不一致」——与独立手算矛盾，举证应撤回。
4. `format.js` 的 Infinity 不可达（用户输入路径有 `Number.isFinite` 校验），低危，不单列。
5. 多处引用数字与前序实测口径不符（`originOnly` 381/930、A/B 172/653），**不得写进验收阈值**。

## 2.4 方法论层面的不足

1. **期望值自产自证**：`baseline2` 原地重写期望值；`baseline-check` 用快照还原费率后自比；手算用例出自同一实现者。核验项数很多（6.9 万/16.4 万），但都是**自洽性/不变量**核验。
2. **两段式求解的最优性边界无置信度**：安全性证据来自自建分支定界 oracle，与引擎**共享同一线性近似设计**；若下界非真下界则「0 漏解」是自证；候选集随 `pGen` 漂移（1076/1021/1021）。
3. **不确定性表达缺失**：截断、区域费范围、区域网损适用性、点对网/子网过境均无区间与翻转标注，而界面用了「全部路径」「三种口径」等超出保证的措辞。
4. **端侧复用假设未被验证**：纯度守卫可绕过 + 契约缺 `LOSS_OF` + iOS 副本漂移 + 端侧验收基线口径不匹配。
