# 原始文件归档

本目录存放费率数据所依据的**一手文件**。归档目的有两个：

1. **可核对** —— 任何一个费率数值都能在此找到来源原件；
2. **防失效** —— 政府网站改版会导致链接失效，原件留存后不受影响。

抓取脚本：`tools/fetch-sources.mjs`（通知正文）、`tools/fetch-attachments.mjs`（PDF 附件）。
抓取日期：2026-09-15。

## 从原件核对出的两处引用错误（已修正）

归档原件后逐条核对，发现数据中的法规引用有两处已过期：

**① 计费口径引用了已废止的文件**

9 条记录（灵绍、祁韶、锡泰、雁淮、扎青、雅湖、陕武、建苏、金塘）原标「依据发改价格规〔2021〕1455号第十九条」。但 **1490号 第二十四条明确：〔2021〕1455号 自 2026-01-01 起废止**。

同一规定现为 **1490号 附件4 第十八条**：

> 专项工程实际输电量按落地端结算电量进行统计确认，结算电量应与落地端物理电量保持一致。因实际线损率与核价线损率偏差产生的损益，按月由购电方承担或享有……

已全部改为引用现行条款。

**② 「单一容量电价」的规则依据引的是 2017 年文件**

定价规则谱系为：`发改价格规〔2017〕2269号` → `〔2021〕1455号` → `〔2025〕1490号`（现行）。

现行 1490号 附件4 **第七条**：跨省跨区专项工程输电价格实行**单一电量电价制**。

同附件后半段保留了例外：

> 对以输送清洁能源电量为主，或以联网功能为主的跨省跨区专项工程，可探索通过两部制或单一容量制形成输电价格

现存的两条单一容量电价制工程与之相符：**辛洹线**（华北—华中间联络线，联网功能为主）、**云霄直流**（闽粤联网工程）。两者的核价文件仍为存量依据（1227号、1604号），数值不受影响。

## 一个意外的印证

本工具把容量制工程按 `容量电价 × 1000 ÷ 4500 小时` 折算成等效度电成本，其中 4500 小时原是按行业惯例取的。核对 1490号 附件4 **第九条**后发现官方定义：

> 设计利用小时按政府主管部门批复的项目核准文件确定，**文件中未明确的原则上按 4500 小时计算**

即该折算口径与官方规则一致，不是拍脑袋取的值。

## 核对方法

`pdftotext -layout <文件> -` 可提取文本后检索数值。例如核对江苏输配电价：

```bash
pdftotext -layout S11-附件1-省级电网输配电价表.pdf - | grep 江苏
```

注意 **842号 附件表的单位是「元/千千瓦时」**，数值上等于 元/兆瓦时，不要误按「分/千瓦时」再乘 10。
