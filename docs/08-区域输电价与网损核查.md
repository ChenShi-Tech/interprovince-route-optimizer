# 区域输电价与网损核查（2026-09-17）

结论：区域输电电量电价应按适用交易计入；区域网损也应按适用的核定或备案口径计入。将区域内部抽象联络接口的计费损耗置零，不等于免除整个区域的网损费用。

| 华中 | 0.0256 | 25.6 |
| 东北 | 0.0164 | 16.4 |
| 西北 | 0.0121 | 12.1 |

附件注1明确电量电价不含线损；注2按区域实际交易结算电量收电量电费；注3容量电价通过省级输配电价回收，不应在已含该项的省级输配电价之外再重复收取。

注4另有京津唐地区交易的电量电费豁免，适用条件包含具体电厂所在地及交易范围。本项目只有省级节点，河北/冀北等尚未细分，不能仅凭经过北京、天津、河北节点就自动豁免，需按真实交易对象确认。本表不含南方电网，不能据此推定南方区域价格为零。

## 区域网损的公开依据与缺口

[2026年省间现货规则](https://www.ndrc.gov.cn/xxgk/zcfb/tz/202604/P020260424330206042944.pdf) 3.4.2(a)规定在买方节点价格折算时计入买方所在区域电网的输电价格和网损，3.3.2要求采用核定或备案标准并排除已经包含在输电价格中的网损。

本次检索了国家发改委1077号附件2、1490号附件3、2026年省间现货规则，以及区域网损率/第四监管周期、华东财务〔2023〕143号、国网与能源局网站等关键词。结果：

- 1077号附件2给出了五区域电量和容量电价，但没有给出对应区域网损率。
- 能检索到第三监管周期历史网损率线索及相关分部文件文号；历史文件的适用周期、交易类型、计量边界需要核实，不能直接填成2026年现行值。
- 能源局东北监管局网站公开的[2025年文件附件](https://dbj.nea.gov.cn/hdhy/dczj/202507/P020250719022575449504.pdf)载有东北互济交易的区域线损口径及公式。这说明区域网损并非无公开依据，但该特定交易及版本不能直接推广成全国当期统一参数。

因此本次没有编造区域网损率，也没有把旧值自动启用。结果对象新增 `regionLossMissing`，结果页与导出报告明确提示本期区域网损费用尚未计入。新疆→上海的 **387.0462 元/MWh** 已含华东9.2元/MWh电量电价，仍缺适用的华东区域网损费用；它是统一假设下的测算值，不是已补齐所有费用的结算价。

同一收费边界应将区域共用网络整体计算一次，不能再把皖苏、苏沪等抽象接口各收一遍区域费或估算网损。跨区域路线应识别实际使用的收费网络及交易规则，不能只按省份经过次数叠加；独立专项工程继续保留各自适用的输电价和网损。
