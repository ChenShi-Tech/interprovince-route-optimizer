# 全国区域共用电网计费审计（2026-09-17）

本次由“新疆→安徽→江苏→上海”重复计费问题触发。按用户指定的交易测算口径，区域内部共用交流接口的计费损耗设为 0，保留独立工程损耗；原物理接口与容量模型保留。

## 原因与修正

1. 构建数据把每个联络接口的 `t/tRev` 填成两侧省份的送出省参考价，旧算法将其逐段当作独立通道价。皖苏、苏沪因此各多收 30 元/MWh，并按下游网损放大。现在仅在路径起点使用该参考价，归入送端省内段；过境接口的独立通道费为 0。
2. 旧算法在每条专项工程前都加一次该省送出价，将中间省份当成新的卖方。现在送出省费仅在交易起点计一次；后续专项工程本身的独立输电价完整保留。缺失的过境省内重要通道价格仍需核定来源，不再用送出价替代。
3. 旧算法对买方之外的每个区域接口都收区域电量电价。同一区域有多段接口时重复计收。现在买方区域计一次，其余共用网络按区域去重，按该区域最后一个接口的计费出口电量归集。
4. 旧算法将区域交流接口的估算线损同时作为交易计费损耗。现在同区域 `regional=true && type==='AC'` 接口的计费损耗为 0；独立专项工程、背靠背直流和原有 `incLoss` 规则保持各自口径。

区域接口仍在路径中，用于连通性、跳数、里程、容量及断面校验。物理估算电量与计费电量明确分开显示。这里的零计费损耗是本工具的测算约定，不是新取得的核定网损率，也不表示区域物理损耗消失。

## 新疆→上海复核

按截图参数：送端出清价 240，新疆送出价 34.3，吉泉输电价 82.9 元/MWh，吉泉计费损耗 7%，华东区域价 9.2 元/MWh；交付电量 1000 MWh，时长 1 小时，不计受端省内费用。

| 分项 | 修复后，元/MWh |
|---|---:|
| 送端出清价 | 240.0000 |
| 吉泉损耗折价 `240 × (1/0.93−1)` | 18.0645 |
| 新疆送出省费用 `34.3/0.93` | 36.8817 |
| 吉泉独立输电价 | 82.9000 |
| 皖苏、苏沪独立通道费 | 0.0000 |
| 华东区域费（一次） | 9.2000 |
| **送到上海省界** | **387.0462** |

修复前 452.5445，降低 65.4982 元/MWh。计费送端电量为 1075.2688 MWh，计费网损为 75.2688 MWh。物理估算链继续使用 7%、0.9%、0.5%，送端估算 1090.4866 MWh、总损耗估算 90.4866 MWh；后者只用于容量检查，不直接作为报价网损收费。

## 全国扫描范围与发现

- 数据库内 30 省，全部 870 个有向省对；分别用“最多 3 段/绕行度 2”和“最多 6 段/绕行度 4”检查，共 1740 组省对及参数、7072 次路径计算。
- 542 个省对的至少一条候选路径金额变化，去重后共 6326 条路径受影响。包含不可行路线，用于排查算法，不表示这些路线都可以成交。
- 5758 条存在中间区域接口误收送出价，6036 条存在后续专项工程重复收送出价，1908 条存在同一过境区域重复收费；三项可重叠。其余影响还包括共用交流接口计费网损归零及起点送出费分类/电量口径修正。
- 修复前后 7072 次路径的物理送达率、物理功率、总物理损耗、里程、容量占用、断面及可行性逐项一致。计费链、电费及排序按新口径更新。
- 这是已录入拓扑和上述参数内的全国扫描。南方区域仍沿用原项目的简化拓扑，不因此成为完整南方市场结算模型；未录入通道或未披露的正式价格未被此测试补齐。

机器可读结果见 [regional-billing-audit.json](regional-billing-audit.json)。

## 验证与复现

`node tools/test-regional-billing.mjs` 包含独立手算、正反向、同区域拆分接口、跨区过境及重新进入同区域、后续专项工程、计费损耗与物理容量分离、区域费开关、完整落地价、费用闭合及三口径排序验证。

可传修复前 HTML：`node tools/test-regional-billing.mjs /path/to/before.html`，生成全国前后对照审计。独立手算用例在旧版实际失败（452.5445 ≠ 387.0462），在新版通过。旧算法基线不能证明新口径正确，因此先用独立用例验证，再重生成 331 个省对、693 条路线的迁移基线。

## 依据与模型边界

[2026 年《省间电力现货交易规则》](https://www.ndrc.gov.cn/xxgk/zcfb/tz/202604/P020260424330206042944.pdf) 3.3.1 要求按核定输电价格执行，并区分专项工程和区域共用电网的电量计量；3.3.2 排除已含在价格中的重复网损；3.4.2(a) 要求计入买方区域电网的输电价和网损。不能据此把一个物理省间接口自动视为一个新的送出省收费单元。

[发改价格规〔2020〕1441号](https://www.ndrc.gov.cn/xxgk/zcfb/ghxwj/202009/t20200930_1243683.html) 第二条说明共用网络的区域电量电价构成。当前数值仍来自仓库第四监管周期价格源，没有改写核定费率。共用交流接口零计费网损及区域去重的具体归集方式属于上述测算约定；正式结算须以相应交易路径和实际执行口径为准。

区域电量电价不含线损（1077号附件2注1）。本期适用的区域网损率尚未核实，当前金额未计区域网损费用，不能解释为该项为零。
本报告的 387.0462 元/MWh 及影响统计均基于“尚未计区域网损”的统一测算口径。公开电价与核查记录见 [区域输电价与网损核查](08-区域输电价与网损核查.md)。
