# 省间电力交易费用计算教程

> **这份教程讲什么。** 把本项目实现的省间交易费用算法，从电量基准、逐层费用到完整公式讲清楚，分**中长期**和**现货**两部分。每个公式里的量都说明含义、单位和出处，每一层都有可复算的数字。
>
> **谁能用。** 做跨省购电测算、外送电报价、路径比选的业务人员和开发人员。不需要读代码。
>
> **不能用来做什么。** 本教程和本工具是**测算**，不是结算。实际结算以交易公告、合同费用约定和电网企业账单为准。第三部分附录 E 列出了已知缺口。

# 第 0 章 通用基础

中长期和现货共用同一套电网模型和电量基准，先把这些讲清楚，后面两部分都不再重复。

## 0.1 三个价格断面

一笔跨省交易的价格，要分清是在**哪个断面**上说的。混淆断面是测算出错最常见的原因。

| 断面 | 含义 | 本教程记号 |
|---|---|---|
| **上网侧** | 送端电厂并网点的电能价格，不含任何输电费 | `p送`（送端报价） |
| **省间交易节点**（俗称"省界"） | 电送到受端省的省间关口，含全部跨省费用，不含受端省内费用 | `p界`（节点交付费用） |
| **到户** | 用户计量点，再加受端省内输配电价、基金等 | `p户`（到户费用） |

> **规则依据**：现货规则 4.2.3「卖方申报**上网侧**电力和价格，买方申报**落地侧**电力和价格」；中长期落地价构成见长三角 2026 细则第三十六条。

## 0.2 网络模型：省是点，通道是边

- **节点**：一个省 = 一个交易节点（现货规则 3.2.1；省内严重阻塞时可拆多节点，本工具不拆）。本工具含 31 个省级节点。
- **边（通道）**：三类，计费方式完全不同——

| 通道类型 | 例子 | 有没有独立输电价 | 计不计段线损 |
|---|---|---|---|
| **跨省跨区专项工程**（直流为主） | 锦苏直流、吉泉直流、灵绍直流 | **有**，发改委逐条核定 | 计（除非核定价已含损） |
| **省间联络线 / 区域共用网架**（交流） | 皖电东送、新甘联络线 | **无**独立核价，按所在区域整体计费 | **不**逐段计，整个区域计一次 |
| **背靠背 / 特殊工程** | 灵宝直流、高岭背靠背 | 部分有 | 按各自核定口径 |

- **方向**：专项工程按核定的送受端方向单向通行；经公开资料证实可双向的工程（德宝、青藏、长南荆、辛洹、灵宝、高岭、云霄）和省间联络线双向通行。**反向时"送端省"变成对侧省**，送出省输电价格随之改取对侧省的值。
- **路径**：一条路径 = 若干条边首尾相接，**不重复经过同一节点**（现货规则 3.2.2）。

当前价库规模：91 条通道（43 条直流 + 46 条交流 + 背靠背），其中 86 条有独立核定价；10 个参考断面；98 个换流站/开关站。

## 0.3 线损：两条电量链

线路有损耗，送出去的电到不了那么多。所有单价都折算到**"每交付 1 MWh 到受端节点"**这个统一基准上。

### 通过率与送达系数

```
某段通过率 = 1 − 该段线损率
送达系数 D = 各段通过率连乘
送端需送出电量 = 1 / D
网损电量 L = 1/D − 1
```

**例**：锦苏直流线损率 7%，`D = 0.93`，要在江苏省界收到 1 MWh，四川侧必须送出 `1/0.93 = 1.0753 MWh`，损耗 `0.0753 MWh`。

### 段前电量与段后电量

```
第 k 段出口电量 = 1 / （第 k 段之后各段通过率的连乘）
第 k 段入口电量 = 第 k 段出口电量 / (1 − 第 k 段线损率)
```

**越靠送端的段，承担的电量越多。** 两段路径的例子（先走线损 2% 的联络线，再走线损 7% 的直流）：

| 段 | 线损率 | 出口电量 | 入口电量 |
|---|---|---|---|
| 第 1 段 联络线 | 2% | 1 ÷ 0.93 = 1.0753 | 1.0753 ÷ 0.98 = 1.0973 |
| 第 2 段 直流 | 7% | 1 | 1.0753 |

### ⚠️ 三条必须记住的计量规则

1. **输电费按"段后电量"收**，不是按入口电量。这直接来自现货规则 4.3.1 的折算公式（推导见 2.4 节）。
2. **输电价格已含网损的通道，不再另收网损**（现货规则 3.3.2）。灵绍、祁韶、锡泰、雁淮、扎青、雅湖、陕武、建苏、金塘等核定文件写明含损的工程，计费时线损按 0。
3. **计费链 ≠ 物理链**。含损通道、区域共用交流接口在**计费链**里线损按 0；**物理链**保留全部实际线损率，用于算功率、容量占用和物理损耗电量。两条链并行计算，不能混用。

## 0.4 单位约定

| 量 | 本工具单位 | 政府文件原文单位 | 换算 |
|---|---|---|---|
| 电价、输电价 | 元/兆瓦时（元/MWh） | 元/千瓦时 | ×1000 |
| 线损率 | 百分数 % | 百分数 / 「不计线损」记 0 | — |
| 电量 | 兆瓦时（MWh） | 亿千瓦时 | 1 亿 kWh = 10⁵ MWh |
| 容量 | 兆瓦（MW） | 万千瓦 | 1 万 kW = 10 MW |

发改价格〔2019〕842 号附件里的「元/千千瓦时」与「元/兆瓦时」数值相同，不必换算。

# 第一部分 省间中长期

## 1. 费用分层总表

中长期交付成本按**七层**累加，到户再加两个可选项。每层都标明：按什么电量收、和路径有没有关系。

| 层 | 费用项 | 计费电量 | 随路径变化 | 主要依据 |
|---|---|---|---|---|
| ① | 电能费 | 交付电量 × 1 | 否 | 合同/交易成交价 |
| ② | 通道网损费 | 网损电量 L | **是** | 现货规则 3.3.2、合同约定 |
| ③ | 送出省输电价格 | 首段入口电量 | 是（只随首段） | 1077 号附件 1 各省表注 4 |
| ④ | 专项工程输电价 | 各段出口电量 | **是** | 842 号等逐条核价文件 |
| ⑤ | 区域电网电量电价 + 区域网损 | 该区域出口电量 | **是** | 1077 号附件 2、1441 号第二条 |
| — | **小计 = 受端省间节点交付费用** | | | |
| ⑥ | 受端上网环节线损费 | 节点价 × ρ/(1−ρ) | 否 | 1077 号附件 1 各省表注 3 |
| ⑦ | 受端省网输配电价 + 政府性基金及附加 | 到户电量 | 否 | 1077 号附件 1 该省表 |
| ⑧* | 容量/需量电费分摊（两部制） | 按用户负荷假设折算 | 否 | 该省两部制容/需量电价 |
| ⑨* | 系统运行费 | 手工填写 | 否 | 各省月度公布 |

\* ⑧⑨ 为到户扩展项，默认不计，需用户提供假设。

## 2. 逐层讲解

全节用同一个例子：**四川电厂 → 锦苏直流 → 江苏**，送端报价 320 元/MWh，网损由买方承担，交付 1 MWh 到江苏省界。

### 2.1 第 ① 层：电能费

买方付给卖方的电能价格，按**交付电量**计一次。

```
电能费 = 送端报价 × 1 = 320.00 元
```

> **报价边界很关键**：`送端报价` 是电厂上网侧电能价格，还是已含送出省费用的"送出关口价"？本工具提供两个选项，见第 5 章。

### 2.2 第 ② 层：通道网损费

损耗掉的电也是卖方发出来的，得有人付钱。承担比例由合同约定，本工具用 `g` 表示买方承担比例（1 = 买方全担，0.5 = 各半，0 = 卖方全担）。

```
通道网损费 = 送端报价 × g × L
           = 320 × 1 × (1/0.93 − 1) = 320 × 0.075269 = 24.09 元
```

**含线损通道此项为 0**（规则 3.3.2）。例：宁夏→浙江走灵绍直流（含损价 48.8 元/MWh），网损费 0，省界价 = 240 + 25（宁夏送出价）+ 48.8 = **313.80 元/MWh**。

### 2.3 第 ③ 层：送出省输电价格

**是什么。** 电从电厂出来要先在送端省自己的电网里走到换流站，这段用的是省级电网，要交过网费。

**从哪来。** 发改价格〔2026〕1077 号附件 1 每张省表下的**注 4**：「外送电送出省输电价格为每千瓦时 X 元（含税、不含线损），送省外上网环节线损率为 Y%」。四川是 0.035 元/kWh = **35 元/MWh**，线损率 0.99%。没有专门核定值的省份适用通用条款「因省间互济等因素临时送省外的电量」0.03 元/kWh = 30 元/MWh，不计线损。

**按什么电量收。** 走过送端省电网的，是进入第一条跨省通道前的全部电量，即**首段入口电量**。

```
送出省段费用 = 送出省输电价格 × 首段入口电量
             = 35 × 1.0753 = 37.63 元
```

**只在交易起点收一次。** 多段路径中，中间省不再重复收送出省价（过境省省内通道价见第 10 章缺口 2）。

**电站专属送出价。** 1077 号附件 1 注 4 对少数电站另定价格与额度，本工具收录了四川 6 项、云南 3 项、河北（冀北）1 项。例如四川「向家坝、溪洛渡左岸、白鹤滩水电站年度合计 1044 亿千瓦时以内的外送电量，送出省输电价格为每千瓦时 0.0232 元（含税），**不计线损**」。选用后覆盖通用送出价：

```
专属价情景：送出省段费用 = 23.2 × 1.0753 = 24.95 元（比通用价少 12.69 元）
```

> 只有四川、云南、冀北这三个主体在原文里给了**具体数值**的电站专属条款，所以界面里只有它们出现「送出价口径」选项；蒙西虽有条款但原文未给数值，不提供选择。

### 2.4 第 ④ 层：专项工程输电价

**是什么。** 跨省跨区专项工程（特高压直流等）由发改委单独核价。锦苏直流：发改价格〔2019〕842 号附件，**51.1 元/MWh，线损率 7%**。

**按什么电量收——最容易算错的一点。** 现货规则 4.3.1 的折算公式写成文字是：

```
折算到卖方的价格 = 买方报价 × 全程通过率 − Σ[ 第 m 段输电价 × 前 m 段累计通过率 ]
```

把两边同除以全程通过率，换成"每交付 1 MWh"的口径，每段费用就变成：

```
第 k 段输电费 = 该段输电价 × 该段出口电量
```

锦苏只有一段，出口就是江苏省界，出口电量为 1：

```
锦苏输电费 = 51.1 × 1 = 51.10 元
```

两段路径的差别一目了然（联络线价 30、损 2%；直流价 51.1、损 7%）：

| 段 | 输电价 | 出口电量 | 输电费 |
|---|---|---|---|
| 第 1 段 联络线 | 30 | 1.0753 | 32.26 |
| 第 2 段 直流 | 51.1 | 1 | 51.10 |

按入口电量收会让锦苏多收 `51.1 × 0.0753 = 3.85` 元，这是本项目 2026-09-15 修正过的一个真实错误。

**容量制工程。** 按容量收费的工程电量边际价为 0（如辛洹线）；输电权交易的工程取输电权价格（云霄直流取报价下限 25.6 元/MWh）。这类工程的容量费用分摊不在本模型内，**不能视为已付清**。

**区域共用交流网架不走这一层。** 同一区域内的交流接口不单独收工程费、不单独计损，整个区域按第 ⑤ 层计一次。

### 2.5 第 ⑤ 层：区域电网电量电价与区域网损

**区域电网是什么。** 省与省之间的 500/750/1000 kV 主网架不属于任何一个省，由发改委单独核价（1077 号附件 2，两部制）。容量电价已通过省级输配电价回收，**交易只付电量电价**：

| 区域 | 电量电价 元/kWh | 折合 元/MWh | 第三监管周期综合网损率（参考） |
|---|---|---|---|
| 华北 | 0.0108 | 10.8 | 2.42% |
| 华东 | 0.0092 | 9.2 | 1.59% |
| 华中 | 0.0256 | 25.6 | 2.54% |
| 东北 | 0.0164 | 16.4 | 2.35% |
| 西北 | 0.0121 | 12.1 | 1.96% |
| 南方 | 无单独核定 | 0 | — |

> ⚠️ 网损率一列是**第三监管周期历史值**，第四周期是否继续适用未核实，只能作参考情景，结果页会保留「待核实」提示。

**每个区域只计一次。** 无论路径在一个区域内走了几条联络线，该区域只在**最后出口**处计一次电量电价和一次网损。绝不逐条接口累加。

```
区域电量费 = 区域电量电价 × 该区域出口电量
区域网损   = 在该区域出口处给通过率链乘上 (1 − 区域网损率)
```

**适用范围有两种口径**（第 5 章详述）：

- **按共用网络归集（默认）**：路径实际走了哪个区域的共用网架，才计哪个区域。直流直接落到受端省、没走区域网架的，不计。
- **公告要求受端区域**：受端省所在区域无论如何都再计一次（对应现货规则 3.4.2(a)「统一计入买方节点所在区域电网的输电价格和网损」）。

**小计：受端省间节点交付费用**

```
节点交付费用 = ① + ② + ③ + ④ + ⑤
```

四川→江苏（锦苏，默认归集口径，路径未走区域网架）：

```
320.00 + 24.09 + 37.63 + 51.10 + 0 = 432.82 元/MWh
```

若按"公告要求受端区域"口径，加华东 9.2：`442.02 元/MWh`。

### 2.6 第 ⑥ 层：受端上网环节线损费

1077 号附件 1 各省表**注 3**：「上网环节线损费用在输配电价外单列，省内上网环节线损率为 ρ受」。江苏 2.83%。

用户要拿到 1 MWh，省内还要损 ρ受，所以要在省界多买：

```
受端线损费 = 节点交付费用 × ρ受 / (1 − ρ受)
           = 432.82 × 2.83% / 97.17% = 12.61 元
```

**电网主体不同，线损率不同。** 河北（河北南网/冀北）、内蒙古（蒙西/蒙东）、陕西（不含榆林/榆林）、广东（不含深圳/深圳）在附件 1 里是分表核价的，注 3 的线损率也各不相同，选错主体结果就错。

### 2.7 第 ⑦⑧⑨ 层：受端省内费用

**⑦ 省网输配电价 + 政府性基金及附加。** 按用户的**电压等级**和**计价方式**取值。以江苏电网为例（1077 号附件 1 第 12 页，工商业用电，元/MWh）：

| 电压档别 | 单一制电量电价 | 两部制电量电价 | 需量电价（元/kW·月） | 容量电价（元/kVA·月） |
|---|---|---|---|---|
| 不满 1 千伏 | 239.1 | — | — | — |
| 1~10（20）千伏 | 213.1 | 129.8 | 51.2 | 32.0 |
| 35 千伏 | 188.1 | 104.8 | 48.0 | 30.0 |
| 110 千伏 | 162.1 | 78.8 | 44.8 | 28.0 |
| 220 千伏及以上 | 135.1 | 51.8 | 41.6 | 26.0 |

**电压等级越高，输配电价越低**——这是到户测算里影响最大的单项。江苏 10 kV 单一制比 220 kV 两部制高出 161.3 元/MWh。

政府性基金及附加按工商业用户口径取值（江苏 29.4 元/MWh）。

**⑧ 容量/需量电费分摊（只有两部制才有）。** 两部制的电量电价不含容量费，必须另算，否则到户价被严重低估。按用户负荷假设折成度电费用：

```
容(需)量分摊（元/MWh）= 月单价 × 12 ÷ (8.76 × 负荷率)
```

- 月单价：按容量取容量电价（元/kVA·月），按需量取需量电价（元/kW·月）。
- 8.76 = 8760 小时 ÷ 1000，把「元/kW·年」换成「元/MWh」的系数。
- 负荷率：用户年均负荷 ÷ 报装容量（或最大需量），由用户给定假设。

**例**：江苏 10 kV 按容量、负荷率 60%：`32 × 12 ÷ (8.76 × 0.6) = 73.06 元/MWh`。这一项比很多人预想的大得多。

**⑨ 系统运行费**：辅助服务、抽蓄容量分摊等，各省按月公布，本工具不预置，需手工填写。

**到户完整口径**

```
到户单价 = 节点交付费用 / (1 − ρ受) + 省网输配电价 + 基金附加 [+ 容需量分摊 + 系统运行费]
到户电量 = 交付电量 × (1 − ρ受)
```

注意：`节点交付费用/(1−ρ受)` 就是 ⑤小计 + ⑥。金额闭合时，⑦⑧⑨ 按**到户电量**计，①~⑥ 按**交付电量**计。

## 3. 统一公式

把七层压缩成四个中间量，这就是本工具算法的全部：

```
D = 计费链上所有通过率的乘积
    = Π(1 − 各段计费线损率) × Π(1 − 各适用区域网损率)
    含损通道与区域共用交流接口的计费线损率按 0

L = 1/D − 1                                    网损电量（每交付 1 MWh）

E = 送端省内网损另计时： (1/D) × ρ送 /(1 − ρ送)   否则 0
    ρ送 = 送省外上网环节线损率（1077 附件1 注4）

F = 送出省输电价格 × 首段入口电量
  + Σ（专项工程输电价 × 该工程出口电量）
  + Σ（区域电量电价 × 该区域出口电量）

A = 1 + g × L + E                              g = 买方网损承担比例
```

于是：

```
节点交付费用 p界 = 送端报价 × A + F
到户费用     p户 = p界 / (1 − ρ受) + p网 + p基金 [+ p容需量 + p系统运行]
可接受送端报价  = (受端目标节点价 − F) / A          ← 反算，见第 6 章
```

**金额闭合校验**（工具内置，曾抓出一次网损重复计算）：

```
Σ各层金额 ÷ 交付电量 ≡ 到户单价
①~⑥ × 交付电量 + ⑦⑧⑨ × 到户电量 = 总金额
```

### 算例 A：四川 → 江苏（锦苏直流直达）

参数：`送端报价 320`、`交付 1000 MWh / 1 h`、`买方承担网损`、江苏 220 kV 及以上两部制。

| 层 | 项目 | 计算 | 元/MWh |
|---|---|---|---:|
| ① | 电能费 | 320 × 1 | 320.00 |
| ② | 通道网损费 | 320 × (1/0.93 − 1) | 24.09 |
| ③ | 送出省输电价格 | 35 × 1.0753 | 37.63 |
| ④ | 锦苏直流输电价 | 51.1 × 1 | 51.10 |
| ⑤ | 区域电网费（默认归集口径，未走华东网架） | — | 0 |
| | **节点交付费用** | | **432.82** |
| ⑥ | 江苏上网环节线损 | 432.82 × 2.83%/97.17% | 12.61 |
| ⑦ | 江苏省网输配电价 + 基金 | 51.8 + 29.4 | 81.20 |
| | **到户费用（已列项小计）** | | **526.63** |

**换口径对比**（同一条路径，只改一个开关）：

| 情景 | 节点交付费用 | 到户费用 |
|---|---:|---:|
| 基准（上表） | 432.82 | 526.63 |
| 送端省内网损另计（+E，ρ送=0.99%） | 436.26 | 530.17 |

| 卖方承担网损（g = 0） | 408.73 | — |

| 到户改 10 kV 单一制（213.1） | 432.82 | 687.93 |
| 到户改 10 kV 两部制 + 容量分摊（负荷率 60%） | 432.82 | 677.69 |

最后两行说明：**到户测算里电压等级和两部制容量费的影响，远大于选哪条跨省通道。**

### 算例 B：新疆 → 上海（吉泉直流 + 华东区域网架）

参数：`送端报价 240`、新疆送出价 34.3、吉泉直流 82.9 元/MWh、损 7%、华东区域电量电价 9.2。路径 `新疆 → 安徽（吉泉直流）→ 上海（皖电东送，华东区域网架）`。

**情景 1：不计区域网损**

```
D = 0.93（只有吉泉的 7%；皖电东送是华东区域网架，计费线损为 0）
节点交付 = (240 + 34.3)/0.93 + 82.9 + 9.2 = 387.05 元/MWh
```

逐项：电能 240 + 网损 18.06 + 送出省 36.88 + 吉泉 82.90 + 华东 9.20。

**情景 2：计入华东第三周期参考网损 1.59%**

```
节点交付 = ((240 + 34.3)/0.93 + 82.9)/(1 − 1.59%) + 9.2 = 393.15 元/MWh
```

注意区域网损落在**华东出口**处，所以它同时抬高了上游各段的电量：吉泉的出口电量从 1 变成 1.016，输电费从 82.90 涨到 84.24。这与长三角跨省中长期实施细则（2026）第三十六条的反推式一致：

```
发电企业上网价格 =（落地侧成交价 − 华东跨省输电价）×（1 − 华东跨省输电网损率）− 送出省外送输电价格
```

### 算例 C：新疆 → 青海（西北 750 kV 区域网架）

路径 `新疆 →（新甘 750 kV）→ 甘肃 →（甘青 750 kV）→ 青海`，两段都是西北区域共用网架。

```
计费链：两段都不单独收输电费、不单独计损 → D = 1
送出省费：新疆 34.3 × 1 = 34.30
区域费：西北 12.1 × 1 = 12.10（整个西北只计一次，不是两次）
节点交付 = 240 + 0 + 34.30 + 0 + 12.10 = 286.40 元/MWh
```

**物理链仍然照算**：两段实际线损各 1.2%，物理送达系数 0.9761，用于功率和容量校验。

## 5. 六个口径开关

同一条路径，换口径就换数。每个开关在公式里的位置都很明确：

| 开关 | 选项 | 落在公式哪里 | 默认 |
|---|---|---|---|
| **报价边界** | 电厂上网价 / 送出关口价 | 送出关口价 ⇒ 去掉 ③ 和 E | 电厂上网价 |
| **送端省内网损** | 报价已含 / 另计 | 另计 ⇒ E > 0 | **另计** |
| **网损承担** | 买方 1 / 各半 0.5 / 卖方 0 | 系数 g | 买方承担 |
| **区域费适用范围** | 按共用网络归集 / 公告要求受端区域 | 决定 F 里有几项区域费 | 按共用网络归集 |
| **区域网损** | 不计入 / 第三周期参考值 / 手填 | 进入 D | **第三周期参考值** |
| **费用边界** | 省间交易节点 / 到户已列费用 | 是否加 ⑥⑦⑧⑨ | 省间交易节点 |

> 两个默认值（送端网损另计、区域网损取参考值）的依据：长三角 2026 细则第三十六条明确落地价含「送出省外送输电网损」和「华东跨省输电网损」，而 1077 号附件 1 注 4 的送出价是**含税、不含线损**、线损率单列。所以不另计就会漏项。

## 6. 反算：可接受的送端报价

给定受端能接受的**节点交付价**，反推最高能给送端多少钱：

```
可接受送端报价 = (受端目标节点价 − F) / A
```

**例**：四川→江苏锦苏，受端目标节点价 560 元/MWh，`F = 37.63 + 51.10 = 88.73`，`A = 1.075269`：

```
(560 − 88.73) / 1.075269 = 438.28 元/MWh
```

含义：送端报价只要不超过 438.28，买方在省界的成本就不超过 560。

⚠️ 这里的目标价是**省间节点价**，不是到户价。要从到户价倒推，先扣掉 ⑦⑧⑨ 再乘 `(1 − ρ受)`。此功能当前版本界面未开放，模型内保留。

## 7. 比选口径与"低费率高线损"陷阱

| 口径 | 算什么 | 方向 | 用途 |
|---|---|---|---|
| **落地成本**（默认排序） | 全部七层 | 越小越好 | 买方选路线的综合标准 |
| **过网费** | 只算 ③ + ④ | 越小越好 | 纯粹的"过路费"比较 |
| **可接受送端报价** | 反算式 | 越大越好 | 卖方视角、议价空间 |

两个口径挑出的最优路线**不总是同一条**：某条线路费率很低但线损很高，按过网费看便宜，加上网损费就贵回去了。这类省对就是需要人工复核的地方。

## 8. 路径是怎么找出来的

```
建图 → 逐层加深枚举简单路径 → 显示等价去重 → 逐条精确计价 → 排序 → 可行性校验
```

1. **建图**：单向工程只挂核定方向，双向工程和联络线挂两个方向。"点对网"电厂送出工程只能作**首段**，不能当过境通道。
2. **枚举**：跳数上限 10，不限绕行。按跳数**由少到多逐层枚举**（迭代加深），每层内按近似成本升序展开，总上限 800 条。
   > 这里有过一个教训：早期用单次深度优先，枚举名额被零费用的区域联络线排列占满，锦苏直流这种直达工程反而进不了候选集，导致四川→江苏的"最低价"是一条绕 7 个省的荒谬路线。逐层加深解决了这个问题。
3. **去重**：同一区域内部走法不同、但计费完全相同的路径（区域网架不逐段收费），合并成一条显示为"X 区域网架"。
4. **计价**：对每条候选路径用第 3 章公式精确计价。**线损是连乘关系，不能直接当最短路的边权**，所以必须先枚举再精算。
5. **可行性**：逐段比对入口功率与通道容量、断面限额。超限的标为不可行。
   > 「未越限」≠「可用输电能力（ATC）已确认」。容量多为参考值，未扣检修和既有占用。

## 9. 怎么读结果里的提示

结果页的每条提示都对应一个**真实的不确定性**，不是免责套话。常见的几条：

| 提示 | 意思 | 该怎么办 |
|---|---|---|
| 区域网损采用第三监管周期参考值 | 第四周期备案文件未公开获取 | 与交易机构核对当期值 |
| 区域收费范围按所选路径假设归集 | 实际收费单元以交易公告为准 | 对照本笔交易公告 |
| 起点送出省输电价格缺项 | 该省注 4 无核定值 | 按临时互济条款或另行确认 |
| 采用送端电站专属送出价 | 有电站范围和年度额度限制 | 确认本笔电量在额度内 |
| 受端按两部制计价，未含容量/需量电费 | 到户价被低估 | 填负荷率做分摊估算 |
| 涉及南方电网 | 南方区域规则本模型未覆盖 | 另行核算 |
| 背靠背接口独立输电价尚未核实 | 未计独立费用 | **不得据此判定免费** |

# 第二部分 省间现货

> 依据：《省间电力现货交易规则》（2026 年 4 月，发改办体改〔2026〕275 号复函附件）。
> **本工具当前只实现中长期测算，现货为规则讲解**，界面保留入口待拓展。

## 1. 现货和中长期是什么关系

```
省间中长期交易   →  确定合同电量与曲线，占用通道能力
        ↓ 在此基础上
省间现货交易     →  利用通道「剩余」输电能力，开展日前、日内电能量交易（实物交易）
```

**跨省区联络线计划安排优先级**（规则 6.1）：

```
跨省区中长期交易  >  省间日前现货  >  省间日内现货
```

组织方：国调中心和网调；省调、交易机构配合。覆盖国家电网与内蒙古电力等经营范围。

## 2. 市场框架

| 项 | 日前 | 日内 |
|---|---|---|
| 交易周期 | D 日未来 24 小时 | 1 小时或 2 小时为一个固定周期 |
| 时段划分 | 00:15–24:00 每 15 分钟一段，**共 96 段** | 24 个（1 h）或 12 个（2 h）固定周期 |
| 组织时间 | D-1 日 11:45–12:30 集中出清 | 周期前滚动组织，可加临时交易 |
| 出清机制 | 集中竞价 | 与日前一致 |

**交易节点**：一般 1 省 = 1 节点；省内严重且频发的阻塞可拆多节点；跨省消纳机组可设独立节点。**同一省内主体之间不得开展省间现货交易。**

**交易路径**：与中长期同构——卖方节点到买方节点的跨省区交直流通道 + 省内重要输电通道顺序链接，不重复经过同一节点，**优先选择输电价格（含网损折价）最低的路径**（规则 3.2.2）。

## 3. 申报规则

买卖双方申报的是**分时「电力–价格」曲线**：卖方报**上网侧**，买方报**落地侧**。

| 要求 | 内容 |
|---|---|
| 分段数 | 每个交易时段最多 **5 段** |
| 单调性 | 卖方曲线**单调非递减**；买方曲线**单调非递增** |
| 最小单位 | 电力 1 MW；价格 1 元/MWh |
| 价格下限 | 参照上年度覆盖范围内各省省内现货申报价格下限的**最低值** |
| 价格上限 | 参照上年度覆盖范围内各省省内现货申报价格上限的**最高值 × 2** |

**申报电力的上限**（防止卖空买空）：

| 主体 | 日前 | 日内 |
|---|---|---|
| 火电/核电卖方 | ≤ 实际发电能力 − 预出清（预计划）；未安排开机的机组不得申报 | ≤ 实际发电能力 − 计划出力 |
| 可再生能源卖方 | ≤ 预测出力 − 预出清（预计划） | ≤ 预测出力 − 计划出力 |
| 售电公司/电力用户买方 | ≤ 所代理用户或自身用电负荷最大值 | 同左 |
| 发电企业买方 | ≤ 省内预出清出力 − 最小技术出力 | ≤ 计划出力 − 最小技术出力 |

**预校核**：省调校核节点内电能可送出/受入，网调校核区域内可执行。不通过的按**价格优先**调减；价格相同按申报电力**等比例**调减，直到通过。

**其他限制**（规则 3.5）：同一主体同一时刻不得既买又卖；节点内部平衡紧张时该节点卖方不得卖出；节点内部有交流断面越限风险时该节点发电企业不得买入。

## 4. 核心公式：买方报价折算到卖方节点

这是现货规则 4.3.1 的原式，也是整个现货出清的基础。**买方在自己节点报的价，要扣掉一路上的输电价和网损，才能和卖方的报价放在同一个节点上比。**

### 原式

```
coe₁      = Π(r=1..N) (1 − ρ_r)                        全程通过率
price_coe = Σ(m=1..N) [ Pt_m × Π(r=1..m) (1 − ρ_r) ]   输电价的通过率加权和

折算后买方价格  price卖买电,j,t = price买电,j,t × coe₁ − price_coe
折算后买方电力  power卖买电,j,t = power买电,j,t / coe₁
```

| 符号 | 含义 | 单位 |
|---|---|---|
| `m` | 交易路径中第 m 段（跨区通道 / 省间联络线 / 区域共用电网） | — |
| `N` | 路径总段数 | — |
| `ρ_r` | 第 r 段输电网损率 | % |
| `Pt_m` | 第 m 段输电价格 | 元/MWh |
| `price买电,j,t` | 买方 j 在 t 时段的落地侧申报价 | 元/MWh |
| `power买电,j,t` | 买方 j 在 t 时段的申报电力 | MW |

**注意两个方向相反的折算**：价格**乘**通过率（买方节点 1 MWh 的价值折到卖方节点要打折），电力**除以**通过率（买方要 1 MW，卖方得多送）。

### 换成「每交付 1 MWh」的口径

两边同除以 `coe₁`，就得到与中长期完全一致的形式：

```
price_coe / coe₁ = Σ [ Pt_m / Π(r>m)(1 − ρ_r) ] = Σ [ 输电价 × 该段出口电量 ]
```

**这就是第一部分 2.4 节"输电费按段后电量收"的出处。** 中长期的 `F` 与现货的 `price_coe/coe₁` 是同一个量。

### 数值例子

路径两段：第 1 段联络线（`Pt₁ = 30`，`ρ₁ = 2%`），第 2 段直流（`Pt₂ = 51.1`，`ρ₂ = 7%`）。买方落地侧报价 500 元/MWh、申报电力 100 MW。

```
coe₁      = 0.98 × 0.93 = 0.9114
price_coe = 30 × 0.98 + 51.1 × 0.98 × 0.93 = 29.40 + 46.57 = 75.97

折算后买方价格 = 500 × 0.9114 − 75.97 = 455.70 − 75.97 = 379.73 元/MWh
折算后买方电力 = 100 / 0.9114 = 109.72 MW
```

校验（换成每交付 1 MWh）：`379.73 / 0.9114 = 416.65`，而 `500 − (30×1.0753 + 51.1×1) = 500 − 83.36 = 416.64`。两条路一致。✓

### 区域电网怎么进来

规则 3.4.2(a)：买方节点申报价向卖方节点折算时，**统一计入买方节点所在区域电网的输电价格和网损**。也就是说区域电量电价和区域网损作为路径的一段（`Pt` 和 `ρ`）进入上式。这一点与中长期的"公告要求受端区域"口径一致。

## 5. 集中竞价出清

```
a) 买方各节点申报曲线 → 按所有可用路径逐一折算到卖方节点
b) 卖方节点上：卖方报价从低到高排序，买方折算后价格从高到低排序
c) 按价差递减撮合：价差 = 折算后买方价 − 卖方报价
   价差最大的交易对优先成交，直到价差 < 0 或路径可用容量 = 0
d) 每成交一笔，扣减该路径可用输电容量和买卖双方申报量
e) 价差相同的多个交易对，按申报电力比例分配
```

**边际价格（规则 4.3.3）**

```
卖方节点出清价 = ( 最后一笔成交交易对的买方折算后价格 + 该交易对的卖方申报价 ) × 0.5
买方节点出清价 = 卖方节点出清价 + 该路径输电价格（含输电网损折价）
```

> 与省内现货的「统一边际出清价」不同：这里是**最后一笔成交对买卖双方报价取平均**，价差在买卖双方之间对半分。

**出清参数（规则 3.4.3）**

- 各跨省区联络线的售电侧出清电力**取整**（直接舍弃小数位）。
- 相邻时段联络线输电功率变化不超过 **600 MW**（允许 ±10 MW 松弛）。不满足爬坡约束时按约束重新出清。

**安全校核（规则 4.4）**：出清过程闭环考虑通道安全约束。结果发布后若因电网边界变化校核不通过，**按灵敏度由高到低顺序取消相关交易**，消除越限，**出清边际电价不变**。

## 6. 结算

### 时间线（规则 7.2.1）

```
D+1   调度机构提供 D 日交易结果与实际执行情况
D+5   市场化交易结果清分，生成日清算结果          （日清月结）
次月第 5 个工作日前   出具上月结算依据（核对版）→ 主体 1 个工作日内核对确认
次月第 8 个工作日前   发布正式结算依据
次月第 10 个工作日前  电网企业发行电费账单
```

### 结算公式（规则 7.3）

**卖方（发电企业）收入**

```
省间现货收入 = 日前执行电量（卖方节点）× 日前出清价（卖方节点）
             + 日内执行电量（卖方节点）× 日内出清价（卖方节点）
```

并且：卖方**自行承担**省间现货与送端省内现货出清产生的盈亏，**按交易电量承担送端省内系统运行费及线损费用**。

> 这正是第一部分缺口 3 的来源：送端省内系统运行费明确由卖方承担，但各省公布方式不一，本工具未采集。

**买方支出**

```
省间现货支出 = 日前执行电量（买方节点）× 折算后日前出清价（买方节点，含输电价格和网损折价）
             + 日内执行电量（买方节点）× 折算后日内出清价（买方节点，含输电价格和网损折价）
```

买方节点为电网企业的，盈亏由受端省代理购电用户分享或分摊；为市场主体的自行承担。

**卖方节点日均结算价格上限（风控）**

```
上限 = 上年度覆盖范围内各省省内现货正式申报价格上限的最高值
```

某卖方节点当日出清加权平均电价超过该上限时，在结算环节对该节点 96 点分时出清电价**等比例调减**至上限，调减后的 96 点电价为结算电价。日前与日内**分别计算、分别触发**。

### 计量

省间结算关口包括：各专项工程送端和受端、省间交流联络线送端和受端、省间点对网电厂及直流配套电源上网侧、省间统分电源上网侧。所有省间结算关口需具备**分时计量**能力。已参与中长期交易的主体，现货计量装置与中长期保持一致。

## 7. 偏差处理（规则 6.2）

省间现货成交结果**纳入联络线计划，作为省内市场的运行边界，原则上不跟随主体实际发用电变化**。

| 主体 | 处理方式 |
|---|---|
| 省内发电企业 | 卖方成交作送端关口负荷增量、买方成交作受端关口电源，参与省内出清结算；省内现货运行时偏差按现货价结算，未运行时按中长期规则考核 |
| 直调发电企业 | 少发优先由内部机组补足 → 其次区域内其他机组调增（保持联络线计划不变）→ 实在不行才申请调整省间现货交易；调增出力的补偿按对应时段省级/区域市场出清均价 |
| 售电公司/电力用户 | 用电偏差按省内现货规则或当地中长期规则处理，**省间现货电能不变** |
| 输电方 | 通道能力下降时按「安全第一」调减或取消省间交易；交流联络线功率波动、网损误差按相关规则处理 |

## 8. 现货与中长期口径对照表 ★

这张表是两部分的接缝，也是最容易出错的地方。

| 项 | 省间中长期（本工具实现） | 省间现货（规则 S14） |
|---|---|---|
| 价格从哪来 | 合同/交易成交价，**用户输入** | 集中竞价**出清**产生 |
| 时间颗粒 | 月度/年度电量与曲线 | 日前 96 段 / 日内 1~2 h |
| 通道能力 | 优先占用 | 用中长期之后的**剩余**能力 |
| 输电费计量 | 段后电量 | 段后电量（4.3.1 推导，**同源**） |
| 含损通道 | 不再另收网损 | 不再另收网损（3.3.2，**同源**） |
| 区域电网费 | 两种口径可选：按共用网络归集 / 受端区域必计 | **统一计入买方节点所在区域**（3.4.2(a)） |
| 送端省内线损 | 可选"报价已含"或"另计" | 明确由**卖方**承担（7.3(a)） |
| 送端省内系统运行费 | 未采集（缺口） | 明确由**卖方**承担（7.3(a)） |
| 网损承担 | 按合同约定，可选比例 | 含在折算式里，由买方折价承担 |
| 路径选择 | 枚举全部候选、按成本排序供人选 | 出清算法在可用路径中自动选价最低者（3.2.2） |
| 价格上限 | 无 | 申报上限 + 卖方节点日均结算价上限 |
| 结算周期 | 月结 | **日清月结**，D+5 清分 |

> **最需要警惕的一条**：现货规则里的结算条款（如受端区域费统一计入、卖方承担送端省内线损与系统运行费）**不能直接套用到中长期合同上**。中长期的费用边界由交易公告和合同约定，本工具默认按共用网络归集并把这些做成可选项，就是这个原因。

## 9. 本工具对现货的支持边界

**已实现**：现货规则里与**费用计算**有关的部分——路径定义、输电价与网损口径、段后电量计量、折算公式的数学等价形式，全部已用于中长期测算并有独立测试交叉验证。

**未实现**：96 时段申报、集中竞价出清、边际价格形成、爬坡与安全校核、日清月结结算。这些需要市场实时数据，不是静态价库能完成的。界面保留现货入口，选择后提示「待拓展」。

## 附录 E 免责与使用边界

1. **这是测算，不是结算。** 公式回归通过只证明给定参数下实现一致，不能证明所有路径均可交易、所有参数均可用于结算。
2. **图连通 ≠ 交易可获批。** 省级单节点模型不区分所有经营区和特定电厂；静态方向不代表规则禁止反向组织。
3. **未越限 ≠ ATC 已确认。** 容量与断面多为参考值，未扣检修与既有占用。
4. **缺项不等于免费。** 标注「待核实」「未获取」的费用项，实际交易中仍可能发生。
5. **南方电网区域**规则本模型未覆盖，涉及南网的结果仅供参考。
6. **政府性基金**按工商业用户口径取值，地方分摊、峰谷分时、力调电费及特殊用户减免未计。
7. 每笔交易的**费用边界以交易公告与合同约定为准**，与本工具默认口径不一致时以前者为准。
