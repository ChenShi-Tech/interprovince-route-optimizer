陕西省发展和改革委员会关于印发《陕西电力现货市场实施细则（V1.0）》等四项细则的通知

国网陕西省电力有限公司，陕西电力交易中心有限公司，各有关经营主体：

为深入贯彻《国务院办公厅关于完善全国统一电力市场体系的实施意见》（国办发〔2026〕4号）等文件精神，落实电力体制改革相关部署，服务全国统一电力市场建设大局，持续巩固改革成效，完善我省电力市场机制，做好中长期与现货市场衔接，我委会同相关单位编制了《陕西电力现货市场实施细则（V1.0）》《陕西电力零售市场实施细则（V1.0）》《陕西电力市场计量管理实施细则（V1.0）》《陕西省间电力现货市场购售电交易实施细则（V1.0）》，在充分征求采纳社会各有关方面意见建议后进一步优化完善，于2026年4月29日经陕西省电力市场管理委员会表决通过，现予以印发。


附件：1.陕西电力现货市场实施细则（V1.0）.pdf

　　　2.陕西电力零售市场实施细则（V1.0）.pdf

　　　3.陕西电力市场计量管理实施细则（V1.0）.pdf

　　　4.陕西省间电力现货市场购售电交易实施细则（V1.0）.pdf
