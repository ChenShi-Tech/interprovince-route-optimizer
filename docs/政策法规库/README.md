## 二、几条必须知道的规则演进

采集过程中核实出的、与常见认知不符的几处：

1. **《电力中长期交易基本规则》（889号，2020）已被取代。**
   现行有效的是 **《电力中长期市场基本规则》（发改能源规〔2025〕1656号）**，
   2025-12-17 印发、**2026-03-01 施行**。889号 与绿色电力交易专章（1123号）同时废止。
   两版都已收录，便于做规则演进比对。

2. **现货市场的顶层规则是 1217号，不是 1077号。**
   《电力现货市场基本规则（试行）》文号为 **发改能源规〔2023〕1217号**，
   2023-09-07 印发、2023-10-15 施行，有效期至 2026-10-15。

3. **《电力市场监管办法》是发改委令第 18 号**（2024-04-12 公布，2024-06-01 施行），
   不是第 21 号令；与《电力市场运行基本规则》（第 20 号令）是两份不同的文件。

4. **辅助服务规则的文号是 发改能源规〔2025〕411号**（2025-04-03），不是 2024 年文。

5. **"1+N"实际已明确为"1+6"**：除运行基本规则外，包含中长期、现货、辅助服务、信息披露、注册、
   计量结算六个专项规则。
