# 省间中长期交付成本与报价测算

给定送端省、受端省与省间节点交付电量，枚举跨省送电的候选路径，按**三种口径并列比选**，并把每一段的输电价、线损、容量占用、费用与核价依据完整拆开展示。

## 快速开始

```bash
node tools/build.mjs        # 由 src/ + docs/ 生成自包含的 index.html
open index.html             # 手机浏览器直接打开即可
```

无构建依赖、无后端、无网络依赖，`index.html` 单文件可离线运行。

**不要直接改 `index.html`** —— 它是构建产物，下次构建会被覆盖。改价格改 `data/fixed-prices.json`，改站点与断面改 `src/extra.json`，改界面改 `src/template.html`。

**想弄懂电费是怎么算出来的，先读 [跨省交易费用计算教程](./docs/10-跨省交易费用计算教程.md)**（同目录有 PDF 版）。它不涉及代码，分中长期与现货两部分，把电量基准、七层费用、统一公式、现货折算与出清讲完，算例可逐项复算。早期版本 [外送电费计算讲解](./docs/06-外送电费计算讲解.md) 保留为历史记录。

## 数据共用（Web 与安卓端）

构建时一次产出三份，**同源同版本**：

| 产物 | 消费方 | 说明 |
|---|---|---|
| `index.html` | Web | 自包含单文件，数据内联，离线可用 |
| `shared/app-data.json` | 安卓端 | 独立 JSON，含 schema 版本与价格指纹 |
| `shared/app-data.min.json` | 安卓端 | 紧凑版，体积少约 25% |

两端通过 `priceVersion` 比对版本，通过 `dataHash` 校验完整性。数据结构、算法约定与回归基准见 [数据接口说明](./docs/03-数据接口说明.md)。

校验两端一致性：`node tools/test-data-share.mjs`

## 数据来源分档

每条费率都带 `tier` 字段，界面上用彩色徽标区分，路径含非核定段时主动告警：

| tier | 含义 | 当前条数 |
|---|---|---|
| `gov` | 国家发改委核定价，有正式文号与原文摘录 | 38 |
| `grid` | 国家电网 / 电力交易中心公开披露价（含报备价） | 8 |
| `region` | 送出省输电价格口径（省间联络线，含渝鄂背靠背） | 18 |
| `est` | 估算或待补 | 见 `docs/gaps.md` |

**不得把报备价与发改委核定价混为一谈。** 2024 年后新投运的部分工程（金永、中衡、坤渝、庆东、宝合）与吉泉、昭沂目前只有国网报备价，无正式核价文件；昭沂的报备价还存在被追溯清算的可能。

## 费用与报价

当前入口为中长期，默认送至受端省间交易节点；现货入口标为待拓展。电能量价格由用户手填，演示预填不是行情；手填后切换省份或重新打开应用会保留。

交付费用 = 手填报价按计费网损折算 + 未含的送出省费用 + 专项工程费用 + 适用区域费用。送出关口报价已经包含的省内费用不重复加收；独立省内网损可按合同边界选择另计。

区域电网电量价有公开标准且不含线损，区域容量费已在省级输配电价回收。中长期区域费范围按路径/交易公告设置，各区域仅一次；皖苏、苏沪等共用接口不独立收费或逐条计损。区域网损提供未计入、历史参考、手填三种情景。

“交易连接与区域计费”按全国区域归属合并连续的区域内共用交流接口，集中展示区域电量价、折合节点交付费用和所选网损情景。同一区域多次出现仍只显示一次费用归集；独立工程和背靠背保持单独展示。接口名称、长度及容量估算可展开核查，连接示意不代表实际潮流路线。展示直接读取既有计价结果，不改变计算公式。

新疆→安徽→江苏→上海，在报价 240、已覆盖送端省内网损、未含送出省费的假设下，不计区域损耗为 **387.05 元/MWh**；加华东历史参考 1.59% 为 **393.15 元/MWh**。后者不是本期核定结果。详细公式、全国审查、数据核验与未覆盖范围见 [全模型审计](docs/09-算法模型与收费标准审计.md)。

## 路线是怎么找出来的

以省为节点、通道为边建图，枚举出发省到目的省之间所有不重复经过同一省的路线（段数上限默认 3、绕行度上限默认 2.0、枚举上限 800 条），再对每条路线用上述费用公式精确计价并按三种口径排序。

网损是连乘关系，不能直接当最短路的边权，所以必须先枚举再精算。枚举时按近似成本从低到高展开，让便宜的路线先出来。必须保留跳数与绕行度上限，否则会算出「内蒙古→山西→河南→湖北→重庆→四川→陕西→山东」这类绕行大半个中国的路径。

默认只展示可行方案，越限方案可选择性显示。四川→上海在 3 段以内可枚举出 11 条路线，放宽到 5 段则为 42 条。

路线唯一标识应使用行进省份序列加边 ID（区分平行通道），不能用边的存储方向：反向通行的联络线，存储方向与行进方向相反，用边拼键会把 A→B→C 与 C→B→A 误判为同一条。凡是用到方向的地方（区域电网费、联络线输电价、绕行度起点）一律按实际行进方向取值。

## 三种口径

| 口径 | 用途 |
|---|---|
| 节点交付费用小计 | 给定送端报价，测算送达成本；可扩展到户已列费用 |
| 过网费 | 未包含的起点送出省费与独立工程费，不含区域费、网损和到户费用 |
| 可接受送端报价 | 给定受端目标交付价，用同一费用假设反推送端报价上限；不是利润 |

## 界面

结果页的主线是**路线浏览**，顺序为：选择出发地/目的地 → 可选路线 → 选中方案详情 → 完整明细。

**可选路线列表**横向排列全部候选，每张卡片显示首段线路名、段数、落地成本、途经省份与里程。可按落地成本／过网费／可接受送端报价三种口径排序；默认列出前 18 条并可展开全部。点击卡片即切换选中方案，详情区与网架图同步更新。

**通道组件**在候选列表上方，把直流（专项工程）等通道当作可选组件来指定方案：点选一条或多条即设为**必经组件**，列表随即只保留同时包含这些通道的路线，不选则显示全部候选。它解决的是枚举替用户做不了的那部分——枚举按全网拓扑跑，不会替人表达「我就想走德宝直流」这类偏好。直流排在最前；组件清单取自绕行度筛选后的完整候选集，所以选中一条后其余组件仍可点选或取消。

界面上的长段口径说明（候选与可行的定义、区域电网费与网损承担方的政策依据）默认收起为一行标题，点开才展开。

**途经节点与线路**用时间轴呈现：每个节点给出省份与换流站/变电站名称及精确站址；每段线路给出名称、电压等级、长度、核定容量、输电价、线损率、段入口功率、段损耗电量、容量占用进度条与费率依据文号。

**完整明细**折叠区包含费用拆解（单价／总额／占比）、断面校验、逐段溯源（文号、原文摘录、调价历史）与口径位置。

**智能推荐**位于页面最右一列：把成本之外的考虑因素用自然语言写下（如「只要发改委核定的线路」「避开占用超过 60% 的通道」），点「让模型推荐」后，浏览器直接调用 OpenAI 兼容的 chat/completions 接口（默认 DeepSeek，可切换智谱 / Moonshot / OpenAI / 自定义地址），模型只在当前可行路线里挑选并给出理由，推荐卡片可点击切换方案。它不参与任何计价与排序，参数一变旧推荐即失效；API Key 只存本机浏览器，不进构建产物。服务商须允许浏览器跨域调用，DeepSeek 与智谱已验证。

**网架图**同时呈现全部 91 条通道与 102 个站点，高亮当前选中方案并标注段序号；未选中时以细线呈现全网架结构。出发地与目的地选定后自动重算，无需点击按钮。

## 验证

```bash
node tools/baseline-check.mjs    # 全绿才算完成（2026-09-18 实测 425 省对 / 987 条路线）
node tools/baseline2.mjs         # 只读核对基线差异 + 渲染冒烟测试 + 底图合规检查
node tools/baseline2.mjs --accept  # 确认差异有来源依据后，才覆写基线
node tools/test-mutation.mjs     # 门禁变异测试：四个反事实必须变红
```

改了费率或通道数据后先跑 `baseline2.mjs` 核对差异；基线默认只读，覆写必须显式 `--accept`。
注意**基线只证明实现未漂移、不证明费率数值正确**（校验时会先用基线里的费率快照覆盖 CH），
费率/数据正确性靠 `audit-fees.mjs`、`audit-voltage-tariffs.mjs` 与一手来源核对。

## 已知缺口

30 个省级主体（发改价格〔2026〕1077号 附件1）的默认高压价及损耗/送出参数已核对，西藏另用自治区发改委文件并校验生效日。主体范围、电压档、政府基金、区域网损现行备案、系统运行费、容量权利以及每笔合同收费范围仍需匹配，详见审计。默认仅算省间节点交付，不能把到户扩展理解为完整结算单。

通道容量与10个历史断面不是当期ATC；联络线容量和物理线损含模型估算。参考未越限不代表可以成交。图模型不实现实际潮流、安全校核、分时合同、执行偏差或现货出清，南方及跨经营区需另核适用规则。
