# 省间电力现货跨省送电路径优选测算

给定送端省、受端省与上网电量，枚举跨省送电的候选路径，按**三种口径并列比选**，并把每一段的输电价、线损、容量占用、费用与核价依据完整拆开展示。

## 快速开始

```bash
node tools/build.mjs        # 由 src/ + docs/ 生成自包含的 index.html
open index.html             # 手机浏览器直接打开即可
```

无构建依赖、无后端、无网络依赖，`index.html` 单文件可离线运行。

**不要直接改 `index.html`** —— 它是构建产物，下次构建会被覆盖。改数据改 `src/extra.json` 与 `docs/tariff.json`，改界面改 `src/template.html`。

## 数据来源分档

每条费率都带 `tier` 字段，界面上用彩色徽标区分，路径含非核定段时主动告警：

| tier | 含义 | 当前条数 |
|---|---|---|
| `gov` | 国家发改委核定价，有正式文号与原文摘录 | 38 |
| `grid` | 国家电网 / 电力交易中心公开披露价（含报备价） | 8 |
| `region` | 区域电网输电价格 / 送出省输电价格口径 | 24 |
| `est` | 估算或待补 | 见 `docs/gaps.md` |

**不得把报备价与发改委核定价混为一谈。** 2024 年后新投运的部分工程（金永、中衡、坤渝、庆东、宝合）与吉泉、昭沂目前只有国网报备价，无正式核价文件；昭沂的报备价还存在被追溯清算的可能。

## 算法要点

**网损是乘法项，不能直接作最短路边权。** 多段串联时送达系数 `D = Π(1−ηᵢ)`，因此采用两步法：

1. 用线性近似权重 `w = 输电价 + 送出省输电价 + 线损率 × 送端出清价 + 区域电网费` 决定邻居展开顺序，深度优先枚举全部简单路径（上限 800 条），得到候选路径集；
2. 对候选路径按乘性公式精确重算并重新排序。

其他几条不能让步的实现约定：

- **专项工程只按核定方向通行，联络线可双向。** 1490 号附件 4 第二条：专项工程「送受端相对明确、潮流方向相对固定」，锦苏、德宝这类直流不能反着走；24 条 500kV 省间联络线（`bidir=true`）可双向，反向行进时输电价取对侧省的送出省价格（`tRev`）。
- **区域电网费只在联络线段计收、专项工程段不收。** 1227 号第五条列出的专项工程购电价格构成里没有区域电网费；1490 号附件 3 第十一条的区域电网电量电费是按「区域共用（交流）网络」的结算电量向购电方收取。联络线段按到达省所在区域取价（跨区联络线取到达区域是本工具的口径假设）。
- **「含输电环节线损」的专项工程价按段后电量计费。** 1490 号附件 4 第九条的输电价格公式已除以 `(1−线损率)`，第十八条按落地端结算电量确认；`incLoss=true` 的 9 条通道若再按段前电量计，线损会被放大两次。其余通道仍按段前电量计。
- **路径唯一标识用节点序列**（`nodes.join('>')`），不能用边的 `from/to` —— 反向通行的联络线其存储方向与行进方向相反，用边拼键会把 `A→B→C` 与 `C→B→A` 误判为同一条。凡是用到边方向的逻辑（区域电网费、联络线输电价、绕行度起点）一律按实际行进方向取值。
- **必须保留跳数上限与绕行度上限**，否则会算出「内蒙古→山西→河南→湖北→重庆→四川→陕西→山东」这类绕行大半个中国的路径。
- **段前电量** = 交付电量 ÷ Π(该段及之后各段的通过率)。越靠送端的段，承担的电量与损耗越多。
- **费用总额必须与单价自洽**：`Σ费用总额 ÷ 交付电量 == 落地单价`。这条校验曾经抓出一次网损重复计算的错误。

## 三种口径

| 口径 | 目标 | 用途 |
|---|---|---|
| 一 · 受端落地购电成本 | 最小化 | 买方视角的综合最优 |
| 二 · 过网费 | 最小化 | 只看通道费率、不计网损，用于识别「费率低但线损高」的陷阱 |
| 三 · 送端折回净收益 | 最大化 | 卖方视角 |

真实费率下（3 段以内、绕行度 2.0），295 个省对中可枚举出 688 条路线，其中 8 个省对的三口径最优路线不一致。

## 界面

结果页的主线是**路线浏览**，顺序为：选择出发地/目的地 → 可选路线 → 选中方案详情 → 完整明细。

**可选路线列表**横向排列全部候选，每张卡片显示首段线路名、段数、落地成本、途经省份与里程。可按落地成本／过网费／送端净收益三种口径排序；默认列出前 18 条并可展开全部。点击卡片即切换选中方案，详情区与网架图同步更新。

**途经节点与线路**用时间轴呈现：每个节点给出省份与换流站/变电站名称及精确站址；每段线路给出名称、电压等级、长度、核定容量、输电价、线损率、段入口功率、段损耗电量、容量占用进度条与费率依据文号。

**完整明细**折叠区包含费用拆解（单价／总额／占比）、断面校验、逐段溯源（文号、原文摘录、调价历史）与口径位置。

**网架图**同时呈现全部 70 条通道与 91 个站点，高亮当前选中方案并标注段序号；未选中时以细线呈现全网架结构。出发地与目的地选定后自动重算，无需点击按钮。

## 路线枚举

出发地与目的地之间的**全部简单路径**（不重复经过同一节点）都会被枚举，而非只取前 K 条。邻居按近似成本升序展开，使低成本路线优先生成；枚举上限 800 条，排序后默认只展示可行方案，越限方案可选择性显示。

四川 → 上海在 3 段以内可枚举出 14 条路线，放宽到 5 段则为 77 条。

## 已知缺口

- 30 个省级参数中仅 7 个（江苏、山东、安徽、湖北、湖南、北京、江西）的输配电价取自官方文件，其余为估算并已在界面标注
- 10 条通道缺额定容量，无法校验占用率
- 500kV 省间联络线（24 条）无单独核定的输电价格，按第四监管周期送端省的**送出省输电价格**口径取值（18.0～49.5 元/MWh，无专属值的省份按通用条款 30 元/MWh），反向行进取对侧省的价格；线路长度亦按站点直线距离估算
- 断面限额（10 个）来自公开报道与学术文献，**不是交易中心披露的运行限额**

## 重要边界

- 本工具是**测算与比选辅助工具**，不构成交易建议，不能替代正式交易系统
- 实际可用的交易路径须在电力交易中心公布的路径集合内；本工具按全网拓扑枚举
- **国网与南网是两套不兼容的模型**：国网省间现货按「交易路径」建模（与本项目的图模型一致）；南方区域市场没有交易路径概念，用断面极限功率 + GSDF 灵敏度约束。覆盖南网省份需另建一套引擎
- 额定容量 ≠ 可用输电能力（ATC）。ATC 的 TRM / CBM 取值我国不公开，工具中不写死默认值
