# 省间电力现货跨省送电路径优选测算

给定送端省、受端省与上网电量，枚举跨省送电的候选路径，按**三种口径并列比选**，并把每一段的输电价、线损、容量占用、费用与核价依据完整拆开展示。

## 快速开始

```bash
node tools/build.mjs        # 由 src/ + docs/ 生成自包含的 index.html
open index.html             # 手机浏览器直接打开即可
```

无构建依赖、无后端、无网络依赖，`index.html` 单文件可离线运行。

**不要直接改 `index.html`** —— 它是构建产物，下次构建会被覆盖。改价格改 `data/fixed-prices.json`，改站点与断面改 `src/extra.json`，改界面改 `src/template.html`。

**想弄懂电费是怎么算出来的，先读 [外送电费计算讲解](./docs/06-外送电费计算讲解.md)**（同目录有 Word 版）。它不涉及代码，用四川→江苏锦苏直流一个例子把七层费用、三种口径和已知缺口讲完。

## 电费是怎么算的

所有单价统一折成「每交付 1 兆瓦时到受端省界」。线路有线损，越靠送端的段承担的电量越多：某段的出口电量 = 1 ÷（这一段之后各段通过率的连乘），入口电量 = 出口电量 ÷（1 − 本段线损率）。

费用分七层叠加，以四川→江苏（锦苏直流，出清价 320，买方承担网损）为例：

| 层 | 内容 | 按什么电量收 | 示例（元/兆瓦时） | 依据 |
|---|---|---|---|---|
| 1 | 电能费 | 交付电量 | 320.00 | 交易结果 |
| 2 | 通道网损费 | 送端多发的电量 × 出清价 | 24.09 | 规则 7.3；含线损通道不收（规则 3.3.2） |
| 3 | 送出省输电价格 | 第一段入口电量 | 37.63 | 1077 号附件 1 注 4 |
| 4 | 专项工程输电价 | 每段的出口电量 | 51.10 | 规则 4.3.1 折算公式 |
| 5 | 区域电网电量电价 | 买方所在区域计一次，过境区域再计 | 9.20 | 规则 3.4.2(a)；1441 号第二条 |
| 6 | 受端上网环节线损费 | 省界价 × 线损率 ÷（1 − 线损率） | 12.87 | 1077 号附件 1 注 3 |
| 7 | 受端省网输配电价 + 基金附加 | 交付电量 | 51.80 + 29.40 | 1077 号附件 1 |
| | **完整落地价** | | **536.09** | |

第 1～5 层之和是「送到受端省界的价格」，「费用边界」选「只算到受端省界」时就停在这里。

2026-09-17 修正了区域接口重复计费：送出省价格仅在交易起点计一次；皖苏、苏沪等区域共用交流接口不收独立通道费，计费线损为 0，物理线损估算继续用于容量校验。新疆→安徽→江苏→上海按出清价 240、吉泉价 82.9、7% 计费损耗测算，省界价由 452.54 降至 **387.05 元/MWh**。全国扫描与复现命令见 [审计报告](docs/07-全国区域计费审计.md)。

几条不能让步的约定：

- **输电费按每段出口电量收，不按入口电量。** 这是规则 4.3.1 的折算公式展开后的结果，之前按入口电量收会多算。
- **「输电价格已含网损」的 9 条直流不再收网损**，但物理损耗照算，用于功率与容量占用。
- **区域电网费按买方所在区域一律计一次**，路线过境其它区域的共用网络按区域去重计一次。区域电网自身网损率未公开，暂按 0。
- **通道方向逐条给定。** 单向直流只按核定方向；德宝、青藏、长南荆、辛洹、灵宝、高岭、云霄经公开报道证实双向运行，反向时送端省内段取对侧省的送出省价格；18 条省间联络线双向。
- **送端与受端的省内线损分开算。** 送出省的「送省外上网环节线损」由卖方承担，只进口径三；受端省的「上网环节线损费用」进完整落地价。
- **费用总额必须与单价自洽**：各层费用总额之和 ÷ 交付电量 == 落地单价。这条校验曾抓出一次网损重复计算。

## 路线是怎么找出来的

以省为节点、通道为边建图，枚举出发省到目的省之间所有不重复经过同一省的路线（段数上限默认 3、绕行度上限默认 2.0、枚举上限 800 条），再对每条路线用上面的七层公式精确计价并按三种口径排序。

网损是连乘关系，不能直接当最短路的边权，所以必须先枚举再精算。枚举时按近似成本从低到高展开，让便宜的路线先出来。必须保留跳数与绕行度上限，否则会算出「内蒙古→山西→河南→湖北→重庆→四川→陕西→山东」这类绕行大半个中国的路径。

默认只展示可行方案，越限方案可选择性显示。四川→上海在 3 段以内可枚举出 11 条路线，放宽到 5 段则为 42 条。

路线唯一标识用省份序列，不能用边的存储方向：反向通行的联络线，存储方向与行进方向相反，用边拼键会把 A→B→C 与 C→B→A 误判为同一条。凡是用到方向的地方（区域电网费、联络线输电价、绕行度起点）一律按实际行进方向取值。

## 三种口径

| 口径 | 目标 | 含义 |
|---|---|---|
| 一 · 受端落地购电成本 | 越小越好 | 七层全算，买方为让 1 兆瓦时到达用户手里一共花多少钱 |
| 二 · 过网费 | 越小越好 | 只取第 3、4 层的纯过路费，用来揪出「费率低但线损高」的陷阱 |
| 三 · 送端折回净收益 | 越大越好 | 受端价与各项过路费都乘以送达系数折回送端，再扣掉卖方承担的网损与送端省内线损，得到卖方每送出 1 兆瓦时净落多少 |

口径一决定买方最多愿意出多少，口径三决定卖方最少要多少，中间就是可谈的空间。

真实费率下（3 段以内、绕行度 2.0），331 个省对中可枚举出 693 条路线，其中 8 个省对的三口径最优路线不一致（均为过网费口径单独最优不同：京>苏、鄂>苏、鄂>浙、蒙>皖、蒙>苏、蒙>沪、蒙>浙、川>晋），口径一与口径三的最优路线全部一致。

## 界面

结果页的主线是**路线浏览**，顺序为：选择出发地/目的地 → 可选路线 → 选中方案详情 → 完整明细。

**可选路线列表**横向排列全部候选，每张卡片显示首段线路名、段数、落地成本、途经省份与里程。可按落地成本／过网费／送端净收益三种口径排序；默认列出前 18 条并可展开全部。点击卡片即切换选中方案，详情区与网架图同步更新。

**通道组件**在候选列表上方，把直流（专项工程）等通道当作可选组件来指定方案：点选一条或多条即设为**必经组件**，列表随即只保留同时包含这些通道的路线，不选则显示全部候选。它解决的是枚举替用户做不了的那部分——枚举按全网拓扑跑，不会替人表达「我就想走德宝直流」这类偏好。直流排在最前；组件清单取自绕行度筛选后的完整候选集，所以选中一条后其余组件仍可点选或取消。

界面上的长段口径说明（候选与可行的定义、区域电网费与网损承担方的政策依据）默认收起为一行标题，点开才展开。

**途经节点与线路**用时间轴呈现：每个节点给出省份与换流站/变电站名称及精确站址；每段线路给出名称、电压等级、长度、核定容量、输电价、线损率、段入口功率、段损耗电量、容量占用进度条与费率依据文号。

**完整明细**折叠区包含费用拆解（单价／总额／占比）、断面校验、逐段溯源（文号、原文摘录、调价历史）与口径位置。

**智能推荐**位于页面最右一列：把成本之外的考虑因素用自然语言写下（如「只要发改委核定的线路」「避开占用超过 60% 的通道」），点「让模型推荐」后，浏览器直接调用 OpenAI 兼容的 chat/completions 接口（默认 DeepSeek，可切换智谱 / Moonshot / OpenAI / 自定义地址），模型只在当前可行路线里挑选并给出理由，推荐卡片可点击切换方案。它不参与任何计价与排序，参数一变旧推荐即失效；API Key 只存本机浏览器，不进构建产物。服务商须允许浏览器跨域调用，DeepSeek 与智谱已验证。

**网架图**同时呈现全部 64 条通道与 91 个站点，高亮当前选中方案并标注段序号；未选中时以细线呈现全网架结构。出发地与目的地选定后自动重算，无需点击按钮。

## 已知缺口

- 30 个省级参数中仅 7 个（江苏、山东、安徽、湖北、湖南、北京、江西）的输配电价取自官方文件，其余为估算并已在界面标注
- 10 条通道缺额定容量，无法校验占用率
- 省间联络线（18 条，含渝鄂背靠背）无单独核定的输电价格，按第四监管周期送端省的**外送电送出省输电价格**取值（18.0～49.5 元/MWh，无外送核定值的省份为临时互济条款 30 元/MWh），反向行进取对侧省的参考价，**只在交易起点计入，不作逐接口收费**；区域共用交流接口计费损耗为 0，物理线损率与容量仍为估算，线路长度按站点直线距离估算
- 区域电网自身的输电网损率、过境省的省内重要输电通道价格、送端省内系统运行费均未公开，未计入。前两项使口径一偏低、口径三偏高，只有多跳过境路线的排序会受影响；第三项只影响口径三的绝对值，不改变排序。西藏无 1077 号附件 1 省表，线损率未获取（各项影响面见 `docs/06-外送电费计算讲解.md` 第五章，出处见 `docs/05-省间现货规则核对与费用口径修正.md` 第四节）
- 断面限额（10 个）来自公开报道与学术文献，**不是交易中心披露的运行限额**

## 重要边界

- 本工具是**测算与比选辅助工具**，不构成交易建议，不能替代正式交易系统
- 实际可用的交易路径须在电力交易中心公布的路径集合内；本工具按全网拓扑枚举
- **国网与南网是两套不兼容的模型**：国网省间现货按「交易路径」建模（与本项目的图模型一致）；南方区域市场没有交易路径概念，用断面极限功率 + GSDF 灵敏度约束。覆盖南网省份需另建一套引擎
- 额定容量 ≠ 可用输电能力（ATC）。ATC 的 TRM / CBM 取值我国不公开，工具中不写死默认值
