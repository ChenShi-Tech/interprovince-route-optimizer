# 阶段 3 · 费率库与地图

> 周期：2–3 周 ｜ 里程碑：**M3 · 可改** ｜ 前置：阶段 2 完成（M2 达成）

---

## 一、核心目标

补上两件让本工具**区别于一张 Excel** 的能力：

1. **费率可编辑、版本可追溯**——发改委每调一次价、核一次线损率，历史测算就换了答案。
2. **网架可看**——路径为什么这么走，一张图比十行表格有用。

---

## 二、关键技术点与所需技能

### 2.1 本地持久化

| 方案 | 适用 |
|---|---|
| **SwiftData**（iOS 17+） | 首选。与 SwiftUI 集成最好，模型即数据类 |
| GRDB | 若需要复杂 SQL 与迁移控制 |

表结构要点：

- **费率表必须带四字段**：`valid_from` / `valid_to` / `source_doc` / `verified_by`。缺一个，任何历史测算都无法复现。
- **版本表**：记录每次变更的时间、变更人、变更前后值。
- **计算留痕表**：输入参数 + `priceVersion` + 引擎版本号。任何一次结果都能原样重算——这条是给审计和复盘用的，不是给技术用的。

### 2.2 导入导出与 schema 校验

- `.json` 走 `fileImporter` / `fileExporter`，`UTType.json`；
- **导入时先校验 schema 再落库**。校验失败要指出**具体是哪个字段、哪条记录、为什么错**——只报一句"格式错误"等于没报；
- 版本比对：`priceVersion` 相同时才允许合并，否则提示用户这是另一套费率。

### 2.3 `tier` 分档与告警

- 字段 `tier` 取值 `gov` / `grid` / `region`，UI 用**彩色徽标**显示；
- 路径含非 `gov` 段时**主动告警**；
- **不得把报备价与核定价混为一谈。** 发改委核定价可获得率约 60%：2018–2019 存量工程、2021–2023 新投运直流可拿到；2024 年后新投运（金永、中衡、坤渝、庆东、宝合）与吉泉、昭沂**只有国网报备价**。
- **不得编造费率数值。** 找不到就写 `null` 并记录已检索路径。

### 2.4 地图（本项目的特有约束）

`src/app/ui/map.js` 第 147 行的注释决定了一切：

> 腾讯地图代理（`http://127.0.0.1:__WB_HTTP_PORT__/...`）只在 WorkBuddy 本地预览环境可用。托管到外网后代理不可用，必须改用天地图或内置拓扑图，否则底图会是一片空白。

**iOS App 里不存在这个代理。** 因此 iOS 端实际可用的地图只有两种：

| 方案 | 特性 |
|---|---|
| **内置 SVG / Canvas 拓扑图** | 完全离线，永远可用。是兜底，也是主力 |
| **天地图** | 需用户在应用内粘贴自己的 tk |

实现要点：

- 用 `WKWebView` 内嵌腾讯地图 GL JS 的现有代码时，`loadFileURL(_:allowingReadAccessTo:)` 是必需的——`file://` 下的资源加载有沙箱限制。**本项目 `index.html` 是自包含单文件，数据已内联，正好绕开这个限制。**
- JS 与原生通信用 `WKScriptMessageHandler`。
- **不得内嵌任何有效地图密钥**；`_TMapSecurityConfig` 的占位符原样保留。
- 白名单之外不使用任何底图（不用 Apple Maps 做业务底图）。

## 三、交付物

| # | 交付物 | 内容 |
|---|---|---|
| 1 | **费率库编辑页** | 列表 + 编辑 + 新增；四字段必填校验；保存后触发重算 |
| 2 | **版本对比页** | 两个 `priceVersion` 并列 diff，标出变化的费率行 |
| 3 | **导入导出** | `.json` 进出；schema 校验失败时给出定位信息 |
| 4 | **地图页** | 内置拓扑图 + 天地图（用户自带 tk）；自动降级逻辑 |
| 5 | **计算留痕** | 每次测算记录输入 + 版本，可回看 |

---

## 四、验收标准

| 项 | 判定 |
|---|---|
| 编辑生效 | 改一条费率，重算结果同步变化 |
| 校验拦截 | 导入一条错误数据能被拦住，并指出**具体字段与原因** |
| 版本追溯 | 任意一次历史测算可用留痕原样重算 |
| 数据纪律 | 找不到的费率显示为「未获取」而非 0 或估算值 |
| 分档告警 | 路径含非 `gov` 段时出现告警；徽标颜色与 `tier` 一致 |
| **地图降级** | **开飞行模式启动，地图页不得空白**——必须落到内置拓扑图 |
| 密钥 | 代码中检索不到任何有效地图密钥 |

## 五、风险

| 风险 | 应对 |
|---|---|
| 腾讯代理在 App 内不存在导致空白 | 内置拓扑图兜底；验收项写死"任何环境不得空白" |
| 编辑历史费率污染当前测算 | 变更不覆盖，写新版本行；旧版本可查 |
| 导入错误数据静默落库 | schema 校验前置；失败必须定位到字段 |
| `tier` 被当成装饰性标签 | 非 `gov` 段强制告警，且成本拆解里显示来源 |
| 西藏基金缺失被按 0 计 | 已显式告警；按 0 计会低估落地成本 |
